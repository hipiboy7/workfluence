# 사내 CA 인증서 자리

사내 LLM이나 사내 IdP(OIDC)가 **사내 인증 기관(CA)이 서명한 https 인증서**를 쓰면, 그 기관의 인증서(PEM)를 이 디렉토리에
**`ca.pem`**이라는 이름으로 두고 앱을 다시 띄운다(`docker compose up -d api`). 앱이 그 기관을 믿는다 — TLS 검증은 끄지 않는다.

- 파일이 없으면 아무 일도 없다. compose를 고치지 않는다
- 기관이 여럿이면 한 파일에 이어 붙인다(PEM 여러 개)
- 이 파일은 저장소에 넣지 않는다(`.gitignore`) — 현장의 것이다

절차 전체는 `docs/운영가이드_반입.md`의 "사내 LLM 연결하기"다. 설계는 `docs/P11_설계서_Ops.md` D.7.
