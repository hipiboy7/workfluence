## 2. 인수 기준 검증 (E2E, `pnpm test:e2e`)

인수 기준: **"관리자가 사용자·스페이스를 관리하고 감사로그로 추적한다. 삭제한 페이지를 휴지통에서 되살린다. 멘션이 알림함에 뜬다"**

```
Running 16 tests using 1 worker
  ✓ e2e/admin.spec.ts:30  › 멘션 → 알림함 → 휴지통 복원 → 라벨
  ✓ e2e/admin.spec.ts:93  › 운영 설정을 바꾸면 다시 띄우지 않아도 먹는다 (NFR-40)
  ✓ e2e/admin.spec.ts:116 › 일반 사용자에게는 운영 설정이 보이지 않는다
  16 passed (14.0s)
```

브라우저에서 확인한 것: 댓글로 동료를 부르면 그 사람 알림함에 뜬다 → 지운 페이지가 휴지통에
있고 되살리면 다시 열린다 → 라벨을 붙이고 라벨로 찾는다 → 관리자가 정책값을 바꾸면
**다시 띄우지 않고** 바로 먹는다 → 일반 사용자에게는 운영 설정 메뉴가 없다.

**대상이 지워진 알림**은 "(지워진 글)"로 뜬다 (FR-506) — 알림은 남되 갈 곳이 없음을 말한다.

## 6. 남은 일 (Phase 4를 끝내려면)

1. **비밀번호 강도 정책값 연결** — 잠금(임계·시간)과 세션(유휴·절대)은 연결했다. 남은 것은 최소 길이·문자 종류다. 지금은 `passwordSchema`(zod)가 `constants`의 고정값을 파싱 시점에 읽어, 관리 화면에서 바꿔도 안 먹는다. 검증을 서비스 층으로 옮겨 살아 있는 값을 쓰게 해야 한다 — **값만 있고 안 쓰이면 `CLAUDE.md` 5절을 어긴 것이다.**
2. **관리 콘솔의 나머지** — FR-530(모든 스페이스 관리)·FR-531(감사로그 거르기)·FR-532(카테고리 관리)가 미착수.
3. **감사로그 보존 정리 명령**.
4. **컨테이너 검증** — 빌드·마이그레이션·실호출.
5. **1.1절 5~7단계** — 자체 점검 넷, 학습가이드, 운영가이드.
6. **병합** — PR + `--no-ff`.
