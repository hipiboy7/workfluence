정상 편집에서는 나오지 않는다 — 프레임 크기의 상한은 보류 27이다.

## 4. 실제로 동작시켜 확인한 것

### 4.1 브라우저 — E2E (`e2e/collab.spec.ts` 마지막 셋)

1. **편집기가 만드는 것은 저장된다** — `연락처 user@example.internal 끝`을 치면 `mailto:` 링크가 생기지 않고, 정렬된 표·제목 붙은
   링크·`rel="opener nofollow"` 링크를 붙여 넣으면 편집기와 저장본의 `rel`이 `nofollow`이며, 그 뒤 **저장하고 보기로**가 보기 화면으로 간다. 착수 확인(2.2)에서는 저장이 실패했다.
2. **인수 기준** — 로그인한 브라우저 안의 WebSocket이 ① 사람 표시에서 읽은 B의 클라이언트 ID로 먼저 쓰고 ② `Y.XmlHook` ③
   `onclick` 속성을 보낸다. 셋 다 `4400`으로 끊기고, A·B는 서로의 편집을 보며, 저장본에 조작한 것이 없고, 감사로그에
   `owner`·`structure`·`structure`가 남는다.
3. **자동 저장이 멈추면 화면이 말한다** (FR-1011) — Phase 9 전의 실시간 상태(가운데 정렬 `textAlign`이 붙은 문단)를 DB에 넣고
   편집 화면을 연다. 다른 문단을 고치면 유휴 뒤 **"자동 저장이 멈췄다: … 'textAlign'"**이 뜨고, 정렬이 붙은 문단을 고치면 배너가
   사라지고 버전이 하나 남는다(저장본에 `textAlign` 없음).

**E2E 전체를 돌리는 동안 관문의 거절은 2번 시험의 셋뿐이었고, 검증 실패는 3번 시험의 하나뿐이었다** — 정상 흐름에서 잘못
거절하거나 저장을 멈춘 것은 0건이다.

  가려졌다. 관문의 묶기가 따로 필요한 경우(주인 없는 기존 클라이언트를 이어 쓰기)의 통합 시험을 더했다.

  게이트웨이가 실제로 넘기는지는 아무 시험도 보지 않았다. 붙어 되풀이된 덩어리를 게이트웨이로 보내는 통합 시험을 더했다.
- **"편집기 — 붙여 넣기 플러그인을 목록에 넣지 않는다"**(세 번째 묶음) — 낱말 빼기와 조각 고치기는 node 시험이 보지만, 플러그인이
  편집기에 실제로 붙는지는 E2E만 봤다. 두 편집기의 확장 목록에 들어 있는지 보는 시험을 더했다(`5fd6bde`).

"저장이 던져도 알리지 않는다"는 그 알림이 `150f76d`에서 저장 사슬로 옮겨 가 첫 실행의 패턴이 어긋났고, 새 자리로 다시 돌려 잡혔다.

## 9. 확인하지 못한 것

- **실제 브라우저에서 조작한 사람 표시**(색·커서)를 보내 동료의 캐럿이 어떻게 그려지는지는 보지 않았다 — 서버가 거르는 것을
  단위·통합 시험으로 봤다. 정상 캐럿이 그려지는 것은 E2E 첫 시험(협업 동료의 이름표)이 본다.
- **자식의 순서·개수가 어긋난 문서**를 받은 편집기가 던지는지는 자체 점검이 몇 가지를 한 번 재 봤을 뿐이다 → 보류 25.
- **프레임 크기 상한**을 두지 않았다. 15만 조각 한 번에 0.5초다 → 보류 27.
- **편집기의 문서·사람 표시 정리**(`CollabEditor.tsx`, 세 번째 코드 리뷰 4)는 E2E가 편집 화면을 오가는 흐름으로만 본다 — web에
  컴포넌트 시험 틀이 없다(보류 28). 연결 상태 기계(`collabLink.ts`)는 node 시험이 있다.
- **끌어 놓기**로 들어온 `rel=opener` 링크는 E2E로 보지 않았다 — 붙여 넣기와 같은 `transformPasted`를 탄다(ProseMirror 동작).
- **정본에서 다시 만든 방에 같은 Y.Doc이 다시 붙어 본문이 두 배가 되는 것**(세 번째 자체 점검 2)은 코드 읽기로만 확인했다 → 보류 26.
- **사람마다 16개 상한에 닿은 뒤**의 모습(첫 글자를 칠 때까지 동료 목록에 안 보인다)은 통합 시험으로만 봤다.
- 옛 데이터(2.5)는 2026-09-24에 센 것을 다시 세지 않았다 — 그 뒤 개발 DB에 들어간 것은 시험이 만든 합성 데이터뿐이다.
- 운영 반입 전이라 **운영 데이터의 옛 `textAlign`**은 세지 못했다. 개발 DB는 0건이다(2.5).
