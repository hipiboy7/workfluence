## 0. 읽기 전에

### 0.1 표기

- 굵은 글씨는 화면에 보이는 글자 그대로다. 메뉴·단추·안내문을 찾을 때 그 글자로 찾는다. 이 문서는 굵은 글씨를 화면 글자에만 쓴다.
- "(기본 30분)"처럼 적은 숫자는 설치할 때의 기본값이다. 대부분은 관리자가 **운영 설정**(19절)에서 바꾸고, 몇 가지(자동 저장까지 기다리는 시간 등)는 서버 설정이다. 그래서 여러분의 위키에서는 다를 수 있다.
- 예로 든 사람·스페이스 이름과 주소(wiki.example.internal 등)는 지어낸 것이다.
- 단축키는 Windows 기준이다. LLM 질문의 **Ctrl+Enter**는 맥에서 Cmd+Enter도 되지만, 왼쪽 칸 접기 **Ctrl+[** 는 맥에서도 Ctrl이다(맥의 Cmd+[ 는 브라우저의 "뒤로"다).
- 화면이 무엇을 알릴 때는 색 띠(알림띠)가 뜨고 앞머리에 **× 오류** · **✓ 완료** · **! 주의** · **i 안내** 가운데 하나가 붙는다. 이 문서가 옮긴 알림 문장에는 이 앞머리를 적지 않았다. 알림띠는 대개 방금 누른 단추가 있는 구획 **안의 맨 위**(구획 제목 아래)에 뜬다.
- 칸 이름 옆의 **필수**는 비워 둘 수 없는 칸이다. 칸 아래의 작은 글씨는 그 칸의 도움말이다.
- 3부 표의 "7.1절" 같은 번호는 [장애 대응 가이드](운영가이드_장애대응.md)의 절이다. 관리 담당에게 그 번호를 함께 알려 주면 원인을 찾는 데 쓴다.

### 0.2 역할의 이름

역할은 한글로 보인다. 모든 화면의 위 막대 오른쪽 **홍길동님 (일반 사용자)** 에서 괄호 안이 내 역할이다. **사용자 관리**(16절)에서는 **일반 사용자 (member)** 처럼 한글 뒤 괄호에 코드가 붙는다. 이 문서는 짧게 쓰려고 코드(member·admin·root)로 적는다.

| 화면의 이름 | 코드 | 할 수 있는 일 |
|---|---|---|
| **일반 사용자** | member | 스페이스를 만들고, 자기가 든 스페이스에서 읽고 쓴다 |
| **관리자** | admin | member의 일에 더해 가입 승인·비밀번호 초기화·세션 끊기·계정 정지, 모든 스페이스, 감사로그, 운영 설정, member에게 일 맡기기(16.7절)(2부) |
| **시스템 관리자** | root | admin의 일에 더해 LLM 연결 관리, 관리자에게 LLM 연결 관리 맡기기, root 역할 주기 |

관리자는 member 한 사람에게 **분류 관리** · **관리자가 건 중지 풀기** · **스페이스 관리 전체**를 맡길 수 있다(16.7절). 맡겨 받은 member는 역할이 member 그대로이고, 맡겨 받은 일만 더 한다.

팀 스페이스 안에서의 자리(Crew의 역할)는 영어로 보이고, owner 말고는 괄호에 뜻이 붙는다. 자세한 것은 2.4절이다.

| 화면의 이름 | 뜻 |
|---|---|
| **owner** | 주인. 그 팀 스페이스를 만든 사람이다. 글을 쓰고, Crew를 넣고 빼고 자리를 바꾸며, 스페이스를 관리한다(2.6절) |
| **editor (쓰기)** | 쓰는 사람. 글을 쓴다 |
| **viewer (읽기만)** | 보는 사람. 읽기만 한다 |

### 0.3 화면의 틀 — 위 막대와 왼쪽 칸

로그인하면 첫 화면(**스페이스** — 내 스페이스 목록)이 나온다. 로그인한 뒤의 화면은 모두 같은 틀이다 — 맨 위의 위 막대, 왼쪽의 왼쪽 칸, 그 옆의 본문. 위 막대와 왼쪽 칸은 어느 화면에서나 그 자리에 있고 본문을 아래로 내려도 제자리에 붙어 있으므로, 어디서든 곧바로 다른 곳으로 간다.

위 막대에는 왼쪽부터 이렇게 놓여 있다.

| 자리 | 보이는 사람 | 하는 일 | 절 |
|---|---|---|---|
| 세 줄 모양 단추 | 모두 | 왼쪽 칸을 접고 편다(아래) | 0.3 |
| **workfluence** | 모두 | 첫 화면(스페이스)으로 간다 | 2 |
| **스페이스** | 모두 | 내 스페이스 목록(첫 화면) | 2 |
| **검색** | 모두 | 페이지를 찾는다 | 7 |
| **LLM 질문** | 모두 | 사내 LLM에게 묻는다 | 14 |
| **휴지통** | 모두 | 지운 페이지를 되살린다 | 13 |
| **관리** | admin·root, 그리고 **스페이스 관리 전체**나 **분류 관리**를 맡겨 받은 member | 관리 화면을 연다. 왼쪽 칸에 관리 메뉴가 보인다(아래) | 15 |
| **알림** | 모두 | 나를 부른 글, 관리자에게는 비밀번호 초기화 요청도. 안 읽은 것이 있으면 옆에 수가 붙는다 | 11.2 |
| **홍길동님 (일반 사용자)** | 모두 | 내 이름과 역할 | 0.2 |
| **비밀번호 변경** | 아이디·비밀번호로 들어온 사람(사내 계정에는 없다) | 내 비밀번호를 바꾼다 | 1.7 |
| **로그아웃** | 모두 | 이 브라우저에서 나간다 | 1.8 |

**스페이스**부터 **관리**까지(주 메뉴)는 지금 있는 곳이 파랗고 굵게, 밑줄이 그어져 보인다 — 페이지 보기·편집도 **스페이스**에, 라벨 화면은 **검색**에 든다.

왼쪽 칸에 무엇이 보이는지는 지금 화면에 따라 셋이다.

| 어느 화면 | 왼쪽 칸에 있는 것 |
|---|---|
| 첫 화면·검색·라벨·알림함·휴지통·비밀번호 변경·관리 화면 | **바로가기** 묶음에 **알림함** · **내 지시문**. 관리 권한이 있으면 그 아래 **관리** 묶음(아래 표) |
| 스페이스 안(스페이스 첫 화면, 페이지 보기·편집·이력) | 스페이스 이름, 그 아래 **팀 · WF7K2M9Q · Crew 3** 같은 한 줄(개인 스페이스는 **개인 · …**), **스페이스 첫 화면**, **새 페이지**(쓸 수 있을 때만), 그리고 페이지 트리(3.3절) |
| LLM 질문·내 지시문 | **새 대화**, **내 지시문**, 대화 목록(14절) |

**관리** 묶음 — 권한이 있는 것만 보인다. 위 막대의 **관리**를 누르면 이 가운데 맨 위의 것이 열린다(admin·root는 **사용자 관리**).

| 메뉴 | 보이는 사람 | 하는 일 | 절 |
|---|---|---|---|
| **사용자 관리** | admin·root | 사람 찾기, 가입 승인, 역할, 잠금 해제, 비밀번호 초기화, 세션 강제 종료, 정지·정지 해제 | 16 |
| **감사로그** | admin·root | 누가 언제 무엇을 했는지 본다 | 18 |
| **스페이스 관리** | admin·root, 그리고 **스페이스 관리 전체**나 **분류 관리**를 맡겨 받은 member | 모든 스페이스를 찾아 중지·다시 쓰기·지우기(스페이스 관리 전체), 분류 만들기·바꾸기·지우기 | 17 |
| **운영 설정** | admin·root | 비밀번호 규칙·로그인 유지 시간·첨부 크기 같은 정책값 | 19 |
| **LLM 연결** | root, 그리고 root가 맡긴 admin | 사내 LLM 서버를 등록하고 지운다 | 20 |

왼쪽 칸은 접을 수 있다. 위 막대 맨 왼쪽의 세 줄 모양 단추(마우스를 올리면 **왼쪽 칸 접기·펴기 (Ctrl+[)**)를 누르거나 Ctrl+[ 를 누르면 왼쪽 칸이 접히고, 한 번 더 하면 펴진다. 글을 쓰는 칸(편집기·입력칸) 안에 커서가 있을 때는 Ctrl+[ 가 먹지 않는다 — 칸 바깥을 누른 뒤 누른다.

- 접었는지 폈는지는 이 브라우저가 기억한다. 다음에 열어도, 다른 화면으로 가도 그대로다. 다른 PC나 다른 브라우저에서는 따로다.
- 한 번도 접거나 편 적이 없으면 창의 폭으로 정한다 — 1280px보다 좁은 창에서는 처음부터 접혀 있다.

### 0.4 확인 대화

아래 목록의 일(지우기·멈추기·빼기처럼 잘못 누르면 되돌리기 어렵거나 번거로운 일)을 누르면 화면 가운데에 확인 대화가 뜬다. 제목은 **이 첨부를 지울까요?** 처럼 묻는 말이고, 그 아래에 무엇이 어떻게 되는지가 적혀 있다.

- 단추는 둘이다 — **그만두기**와, **지운다** · **뺀다** · **멈춘다** · **넘겨받는다** · **없앤다** 처럼 누른 단추와 다른 낱말의 확정 단추. 확정 단추를 눌러야 그 일을 한다.
- 처음에는 **그만두기**에 초점이 있다. Enter를 그대로 누르거나 Esc를 누르면 그만둔다.
- 묻는 것: 첨부 지우기(8절), 댓글 지우기(9절), 템플릿 지우기(17.3절), Crew에서 빼기(2.3절), 스페이스 중지·지우기·관리자가 건 중지로 바꾸기(2.6·17.1절), 분류 지우기(2.6·17.1절), 사용자 정지(16.10절), 비밀번호 초기화(16.5절 — 확정 단추는 **새로 만든다**), LLM 연결 삭제(20절), LLM 대화 지우기(14.6절), 지시문 지우기(14.5절).
- 묻지 않는 것: 페이지 삭제(휴지통에서 되살린다, 3.4절), 옛 버전으로 복원(이력이 남는다, 6.3절), 라벨 떼기(다시 붙인다, 10절), 다시 쓰기, 정지 해제, 되살리기처럼 되돌리는 쪽의 일, 그리고 사용자 관리의 **세션 강제 종료**·역할 바꾸기(누르면 곧바로 먹는다 — 16절).

# 1부 모든 사용자

## 1. 처음 들어가기

### 1.1 로그인

1. 브라우저에서 위키 주소(예: https://wiki.example.internal)를 연다. 로그인하지 않았으면 어느 주소로 들어가도 로그인 화면이 나온다. 회색 바탕 가운데 **workfluence** 아래에 **로그인** 카드가 있다.
2. **아이디**와 **비밀번호**를 넣고 **로그인**을 누른다. 누르는 동안 단추가 **확인 중…** 이 된다.
3. 첫 화면(스페이스 목록)이 나온다.

로그인이 안 되면 카드 안에 **아이디 또는 비밀번호가 올바르지 않다**가 뜬다. 아이디가 없을 때, 비밀번호가 틀렸을 때, 아직 승인 전일 때, 잠겼을 때, 관리자가 정지했을 때 모두 같은 말이다. 어떤 아이디가 있는지 바깥에 알리지 않으려고 일부러 가리지 않는다. 까닭은 관리자가 감사로그에서 본다(22절).

로그인 카드 아래에 **가입 요청** · **아이디·비밀번호 찾기** · **시스템 관리자 아이디 찾기**가 있다.

### 1.2 사내 계정으로 로그인

회사의 로그인 시스템과 이어 둔 위키에는 로그인 카드의 **로그인** 단추 아래, **또는** 다음에 **사내 계정으로 로그인** 단추가 있다. 서버에서 켜 둔 경우에만 보인다.

- 누르면 회사 로그인 화면을 거쳐 돌아오고 첫 화면이 열린다.
- 가입 요청과 승인이 필요 없다. 처음 들어오면 계정과 개인 스페이스가 저절로 생긴다.
- 역할(member·admin 등)과 이름·email은 회사 로그인 시스템의 정보로 정해지고, 로그인할 때마다 다시 맞춰진다.
- 이 위키의 비밀번호가 따로 없다. 그래서 위 막대에 **비밀번호 변경**이 없다. 주소를 알고 그 화면을 열면 **사내 계정으로 로그인했다. 비밀번호는 사내 계정(IdP)에서 바꾼다.** 와 **홈으로** 단추만 보인다. **아이디·비밀번호 찾기**도 쓰지 않는다.
- 관리자가 정지한 계정은 회사 로그인을 거쳐도 들어가지 못한다: **이 계정은 정지돼 있다 — 관리자에게 문의한다**(16.10절).
- 들어가지 못하면 브라우저에 까닭을 담은 글이 뜬다. 22절 표에서 그 까닭을 찾는다.

### 1.3 가입 요청 — 승인 대기 — 활성

사내 계정이 없으면 이 위키의 계정을 만든다. 곧바로 쓸 수는 없고 관리자가 승인해야 한다.

1. 로그인 카드 아래의 **가입 요청**을 누른다. **가입 요청** 카드가 열린다.
2. 칸을 채운다.

| 칸 | 넣을 것 |
|---|---|
| **아이디** | 로그인할 때 쓰는 이름. 영문 소문자, 숫자, 그리고 마침표·밑줄·빼기표만 쓰고 2자부터 64자까지다. 다른 사람이 나를 부를 때도 이것을 쓴다(11절) |
| **이름** | 다른 사람에게 보이는 이름. Crew 목록·댓글·알림에 나온다 |
| **email** | 아이디 찾기(1.5절)에 쓰고, 누가 나를 부르면 메일이 이 주소로 간다(11.3절) |
| **비밀번호** | 칸 아래 안내를 지킨다. 기본 규칙이면 **8자 이상, 영문 대·소문자·숫자·특수문자 중 2종 이상, 공백 없이**다 |

3. **가입 요청**을 누르면 칸들이 사라지고 그 자리에 **가입 요청이 접수됐다. 관리자가 승인하면 로그인할 수 있다. 승인 전에는 로그인되지 않는다.** 가 뜬다. 이때부터 승인 대기다. 카드 아래의 **← 로그인으로**로 돌아간다.
4. 관리자가 승인하면 로그인된다. 승인 전에 로그인하면 **아이디 또는 비밀번호가 올바르지 않다**가 뜬다.

- 가입을 요청했다는 알림이 관리자에게 저절로 가지 않는다. 서두르려면 관리자에게 직접 말한다.
- 승인되면 개인 스페이스 **홍길동의 공간**이 생긴다.
- **이미 사용 중인 아이디이거나 등록된 email이다**가 뜨면 다른 아이디를 쓴다. email이 겹친다면 전에 만든 계정이 있을 수 있다. 1.5절로 찾는다.
- 비밀번호 규칙은 관리자가 바꿀 수 있다(19절). 칸 아래 안내문도 그 규칙을 따라 바뀐다. 규칙에 맞지 않으면 화면이 까닭을 말한다.
- 같은 곳에서 10분에 다섯 번까지 요청할 수 있다.

### 1.4 임시 비밀번호로 처음 들어갈 때

관리자가 비밀번호를 초기화하면 임시 비밀번호를 받는다. 관리자가 직접 전해 준다.

1. 임시 비밀번호로 로그인한다.
2. 로그인 화면처럼 회색 바탕 가운데에 **비밀번호 변경** 카드가 열리고, 카드 제목 아래에 **비밀번호를 변경해야 계속할 수 있다.** 가 보인다. 위 막대와 왼쪽 칸이 없다 — 바꾸기 전에는 다른 화면으로 가지 못한다.
3. **지금 쓰는 비밀번호** 묶음의 **현재 비밀번호**에 임시 비밀번호를, **바꿀 비밀번호** 묶음의 **새 비밀번호**와 **새 비밀번호 확인**에 앞으로 쓸 비밀번호(칸 아래 안내의 규칙대로)를 넣고 **변경**을 누른다. 바꾸기 전에 나갈 길은 카드 아래의 **로그아웃**뿐이다.
4. 첫 화면으로 간다.

### 1.5 아이디를 잊었을 때

1. 로그인 카드 아래의 **아이디·비밀번호 찾기**를 누른다. 카드 둘이 나란히 열린다 — 왼쪽이 **아이디 찾기**, 오른쪽이 **비밀번호 찾기**(1.6절)다.
2. **아이디 찾기** 카드에 **email**과 **이름**을 가입할 때와 같게 넣고 **찾기**를 누른다.
3. 맞으면 그 카드 안에 **아이디:** 다음에 아이디가 나오고 **(일부만 표시된다)** 가 붙는다. 앞 몇 글자만 보이고 나머지는 가려진다.
4. 맞지 않으면 같은 자리에 **일치하는 정보로 찾을 수 없다. 관리자에게 문의한다.**

두 카드 아래의 **← 로그인으로**로 돌아간다.

1분에 다섯 번까지 해 볼 수 있다.

### 1.6 비밀번호를 잊었을 때

- 시스템 관리자(root)의 아이디를 모르면 로그인 카드 아래의 **시스템 관리자 아이디 찾기**를 누른다. 안내 카드 하나가 열린다 — 시스템 관리자의 아이디는 **설치할 때 정한 값**이고 따로 정하지 않았으면 `root`다. 그 아래 **서버 담당자가 확인하는 법**(반입한 서버의 설정 파일에서 WF_ROOT_USERNAME 줄을 보거나, 데이터베이스에서 보는 명령 한 줄)과 **비밀번호를 잊었을 때**(다른 시스템 관리자에게 부탁하고, 한 사람뿐이면 서버 담당자에게 알린다 — 장애 대응 가이드 7.29절)가 있다. 그 화면은 누구의 아이디도 보여 주지 않는다. 카드 아래의 **← 로그인으로**로 돌아간다.

**비밀번호 찾기**(아이디·비밀번호 찾기 화면의 오른쪽 카드)에서 비밀번호를 바로 바꿀 수는 없다. 관리자에게 초기화를 요청하는 것이다. 그 카드도 그렇게 말한다: **비밀번호는 이 화면에서 바로 바꿔 드리지 않는다. 요청을 남기면 관리자가 확인하고 초기화한다.**

1. **아이디·비밀번호 찾기** 화면 오른쪽의 **비밀번호 찾기** 카드.
2. **아이디**와 **email**을 넣고 **초기화 요청**을 누른다.
3. 그 카드 안에 **요청을 접수했다. 아이디와 email이 맞으면 관리자의 알림에 간다 — 관리자가 초기화한 임시 비밀번호를 받아 로그인한다.** 가 뜬다. 넣은 값이 맞지 않아도 같은 말이 뜬다.
4. 넣은 아이디와 email이 맞으면 그 계정을 관리할 수 있는 관리자와 시스템 관리자의 **알림**에 요청이 간다(16.5절). 관리자가 초기화해 임시 비밀번호를 전해 주면 1.4절로 들어간다. 급하면 관리자에게 직접 연락한다.

10분에 세 번까지 요청할 수 있다.

### 1.7 비밀번호 바꾸기

1. 위 막대 오른쪽의 **비밀번호 변경**을 누른다. 위 막대와 왼쪽 칸은 그대로이고 본문에 **비밀번호 변경** 폼이 열린다.
2. **지금 쓰는 비밀번호** 묶음의 **현재 비밀번호**, **바꿀 비밀번호** 묶음의 **새 비밀번호**·**새 비밀번호 확인**을 넣고 **변경**을 누른다. 칸 오른쪽의 눈 모양(처음은 감은 눈)을 누르면 넣은 글자가 보이고, 다시 누르면 가린다.

- 바꾸면 첫 화면으로 간다. 지금 이 창은 로그인이 이어지고, 다른 컴퓨터·다른 브라우저의 로그인은 모두 풀린다.
- 이 브라우저의 다른 탭에서 열어 둔 편집 화면도 끊긴다. 새로고침하면 다시 붙는다.
- 새 비밀번호는 지금 비밀번호와 달라야 하고, 칸 아래 안내의 규칙을 따른다. 그 안내는 관리자가 정한 규칙대로 나온다.
- 같으면 **새 비밀번호가 현재 비밀번호와 같다 — 다른 비밀번호를 쓴다**, 확인이 다르면 **새 비밀번호와 확인이 다르다**가 그 칸 아래에 뜨고 **변경**을 누를 수 없다.
- 바꾸지 않고 나가려면 폼 아래 **변경** 옆의 **← 뒤로**(앞 화면)나 **홈으로**(첫 화면)를 누른다. 위 막대의 메뉴로 가도 된다.
- 사내 계정으로 들어온 사람에게는 이 메뉴가 없다(1.2절).
- **로그아웃**은 이 화면에서도 위 막대 오른쪽에 있다.

### 1.8 로그아웃

위 막대 맨 오른쪽의 **로그아웃**을 누른다. 로그인한 뒤의 모든 화면에 있다. 로그인 화면으로 돌아간다. 비밀번호를 바꿔야 하는 동안(1.4절)에는 위 막대가 없고, 카드 아래의 **로그아웃**을 누른다.

- 이 브라우저의 로그인만 끝난다. 다른 컴퓨터에 로그인해 둔 것은 그대로다.
- 이 브라우저에서 열어 둔 편집 화면은 끊긴다.

### 1.9 로그인이 저절로 풀리는 때

| 언제 | 기본값 |
|---|---|
| 아무것도 하지 않고 이만큼 지나면 | 30분 |
| 로그인한 뒤 무엇을 하고 있든 이만큼 지나면 | 12시간 |

두 값은 관리자가 운영 설정에서 바꿀 수 있다(19절).

- 편집 화면에서 글을 고치고 있으면 로그인이 이어진다. 띄엄띄엄 고쳐도 된다 — 30분(기본)이 지나기 전에 한 번씩 고치면 풀리지 않는다. 편집 화면을 열어만 두고 손을 놓으면 풀리고, 편집 연결도 끊긴다. 12시간은 글을 치고 있어도 지켜진다.
- 풀린 뒤 무엇을 누르면 오류 알림띠에 **로그인이 필요하다**나 **세션이 만료됐다 (절대 타임아웃)** 가 뜬다. 세션은 로그인해 있는 상태를 말한다. 새로고침(F5)하면 로그인 화면이 나온다. 다시 로그인하고 하던 곳을 찾아 들어간다.
- 편집 중이었다면 새로고침하기 전에 쓰던 글을 복사해 둔다(5.4절).
- 로그아웃, 비밀번호 변경, 관리자의 세션 강제 종료도 로그인을 끝낸다.

### 1.10 비밀번호를 여러 번 틀리면

- 비밀번호를 5번(기본) 틀리면 계정이 15분(기본) 잠긴다. 잠긴 동안에는 맞는 비밀번호로도 **아이디 또는 비밀번호가 올바르지 않다**가 뜬다.
- 기다리면 저절로 풀린다. 급하면 관리자에게 잠금 해제를 부탁한다(16.4절).
- 동시에 여러 번 보내도 한 번씩 세어진다. 같은 아이디로 여러 창에서 한꺼번에 로그인하면 하나씩 차례로 처리된다.
- 기다려도 풀리지 않고 비밀번호도 맞다면 관리자가 **정지**했을 수 있다. 관리자에게 묻는다(16.10절).
- 같은 곳(같은 주소)에서 1분에 20번 넘게 로그인에 실패하면 **요청이 너무 잦다. 1분 후 다시 시도한다**가 뜬다. 1분 기다린다.

## 2. 스페이스

### 2.1 개인 스페이스와 팀 스페이스

스페이스는 페이지를 모아 두는 공간이다. 두 가지가 있다.

| 종류 | 목록의 표시 | 누가 보나 | 어떻게 생기나 |
|---|---|---|---|
| 개인 | **개인** | 나와 관리자만 | 승인될 때(사내 계정은 처음 들어올 때) 하나가 저절로 생긴다. 이름은 **홍길동의 공간**처럼 붙는다 |
| 팀 | **팀** | 그 스페이스의 Crew와 관리자 | 누구나 만든다(2.2절) |

첫 화면(**스페이스**)의 **내 스페이스** 표에는 내가 볼 수 있는 것만 나온다. 열은 **이름** · **종류**(**개인**·**팀**) · **키**(스페이스 기호 — WF로 시작하는 여덟 글자. 스페이스마다 다르다) · **Crew**(사람 수) · **상태**(**활성**, 중지된 것은 **중지** — 2.5절)다. 분류(2.6절)가 붙은 스페이스가 하나라도 있으면 **키** 다음에 **분류** 열이 생긴다. 이름을 누르면 그 스페이스가 열린다. 하나도 없으면 **아직 스페이스가 없다.** 와 **팀 스페이스를 만들거나, 팀 스페이스의 주인에게 Crew로 넣어 달라고 부탁한다.**

Crew가 아닌 팀 스페이스는 목록에 나오지 않고, 주소를 알고 열어도 **스페이스를 찾을 수 없다**가 뜬다. 그런 스페이스가 있다는 사실조차 알리지 않으려고 일부러 그렇게 했다.

### 2.2 팀 스페이스 만들기

1. 첫 화면의 **내 스페이스** 표 위에 있는 **팀 스페이스 만들기**의 **이름** 칸에 이름을 넣는다(예: 기획팀 공간).
2. **만들기**를 누르면 표에 생긴다. 만든 사람이 그 스페이스의 owner가 된다.

개인 스페이스는 화면에서 새로 만들지 않는다. 이름·설명·분류를 바꾸거나 중지하고 지우는 일은 스페이스 첫 화면 아래쪽의 관리 칸(**스페이스 정보** · **분류 관리** · **위험 구역**)에서 한다(2.6절).

### 2.3 Crew 넣고 빼기

팀 스페이스의 첫 화면(왼쪽 칸의 **스페이스 첫 화면**)에서 제목 아래(쓸 수 있으면 **새 페이지** 구획 다음)에 **Crew** 칸이 있다. 표의 열은 **이름** · **아이디** · **역할**(**editor (쓰기)** 같은 자리)이다. owner와 관리자에게는 owner가 아닌 줄의 **역할** 칸이 고르기로 보인다(아래 자리 바꾸기).

- 넣기: owner와 관리자에게 표 아래 **아이디로 Crew 추가** 칸과 **역할** 고르기가 보인다. 넣을 사람의 아이디를 쓰고 역할 — **editor (쓰기)** 또는 **viewer (읽기만)** — 을 고른 뒤 **추가**를 누른다. 고르지 않으면 editor다.
- 자리 바꾸기: owner가 아닌 사람 줄의 역할 고르기에서 바꾼다. 고르는 즉시 바뀐다. owner 줄은 바꾸지 못한다.
- 빼기: owner가 아닌 사람 줄 끝의 **제거**를 누르면 확인 대화 **Crew에서 뺄까요?** 가 뜬다(0.4절). **뺀다**를 누르면 빠진다 — Crew로 받은 읽기·쓰기가 사라지고, 다시 넣으면 돌아온다. **그만두기**면 그대로다.
- 뺀 사람이나 viewer로 바꾼 사람이 그 스페이스의 페이지를 편집하고 있었다면 몇 분 안에(기본 5분) 그 사람의 편집 연결이 끊긴다.
- **사용자를 찾을 수 없다**가 뜨면 아이디를 확인한다. **이미 Crew에 있다**는 벌써 들어 있다는 뜻이다.
- **관리자가 중지한 스페이스에서는 owner도 Crew를 바꾸지 못한다**(넣기·자리 바꾸기·빼기 모두) — 넣기 칸·역할 고르기·**제거**가 없고, Crew 칸 맨 위에 **관리자가 중지한 스페이스라 Crew를 바꾸지 못한다 — 관리자에게 부탁한다. 다시 쓰게 되면 주인도 바꾼다.**가 보인다. 스스로 풀 수 있는 owner(**관리자가 건 중지 풀기**나 **스페이스 관리 전체**를 받았다)에게는 **관리자가 중지한 스페이스라 Crew를 바꾸지 못한다 — 아래 관리 칸의 다시 쓰기로 먼저 풀면 바꾼다.**가 보인다. 관리자는 바꾼다. owner가 스스로 중지한 스페이스에서는 그대로 바꾼다(2.5절). 화면을 열어 둔 사이 관리자가 중지했으면, 누른 뒤 Crew 칸에 **관리자가 중지한 스페이스다 — Crew는 관리자가 바꾼다**가 뜨고 화면이 다시 읽어 칸이 안내로 바뀐다.

### 2.4 자리마다 할 수 있는 일

팀 스페이스에서:

| 할 일 | viewer | editor | owner | 관리자 |
|---|---|---|---|---|
| 페이지 읽기, 이력 보기, 첨부 내려받기, 댓글 읽기 | ○ | ○ | ○ | ○ |
| HTML로 내보내기, 텍스트·마크다운 복사 | ○ | ○ | ○ | ○ |
| 페이지 만들기·고치기·지우기, 옛 버전으로 되돌리기 | — | ○ | ○ | ○ |
| 첨부 올리기·지우기, 라벨 붙이기·떼기, 댓글 쓰기 | — | ○ | ○ | ○ |
| 휴지통에서 이 스페이스의 페이지 되살리기 | — | ○ | ○ | ○ |
| Crew 넣고 빼기, 자리 바꾸기 | — | — | ○ (관리자가 중지한 동안은 못 한다 — 2.3절) | ○ |
| 스페이스 이름·설명·분류 바꾸기(2.6절) | — | — | ○ | ○ |
| 스페이스 중지·다시 쓰기(2.6절) | — | — | ○ (관리자가 건 중지는 **관리자가 건 중지 풀기**를 받은 owner만 푼다 — 2.5절) | ○ |
| 스페이스 지우기(2.6절) | — | — | 활성이고 Crew가 본인뿐일 때 | 중지된 스페이스 |

- 개인 스페이스에서는 만든 사람과 관리자가 위의 일을 모두 한다. Crew는 없다.
- 템플릿 만들기(17.3절)는 관리자만 한다. 지운 스페이스 되살리기(17.2절)는 관리자와 **스페이스 관리 전체**를 맡겨 받은 사람이 한다.
- **스페이스 관리 전체**를 맡겨 받은 member는 Crew가 아닌 스페이스도 **스페이스 관리** 화면에서 중지·다시 쓰기·지우기(중지된 것)를 한다. 다만 그 안의 페이지를 읽거나 이름을 바꾸지는 못한다 — Crew가 아니면 열어도 **스페이스를 찾을 수 없다**가 뜬다.
- 중지된 스페이스에서는 누구도 쓰지 못한다(2.5절).

### 2.5 중지된 스페이스

중지된 스페이스는 첫 화면 표의 **상태**에 **중지**, 스페이스 첫 화면의 제목 아래에 **중지됨 — 읽기만 된다**가 붙는다. 관리자를 포함해 아무도 고치지 못하고 읽기만 된다. 다만 중지하던 때 편집 화면을 열어 두고 있던 사람은 곧바로가 아니라 몇 분 안에(기본 5분) 연결이 끊긴다 — 그때까지 친 것은 저장된다. 중지와 다시 쓰기는 owner와 관리자가 스페이스 첫 화면의 관리 칸(**위험 구역** — 2.6절)에서, 관리자는 **스페이스 관리** 화면(17.1절)에서도 한다. **스페이스 관리 전체**를 맡겨 받은 사람도 **스페이스 관리** 화면에서 한다(16.7절).

**누가 중지했나에 따라 푸는 사람이 다르다.**

- owner(개인 스페이스는 만든 사람)가 스스로 중지했으면 관리 칸 맨 위에 **주인이 중지한 스페이스다.**가 보이고, owner가 **위험 구역**의 **다시 쓰기**로 푼다.
- 관리자가 중지했으면 **관리자가 중지한 스페이스다.**가 보이고, owner는 풀지 못한다 — 그 뒤에 **주인도 다시 쓰기로 풀지 못한다 — 관리자에게 부탁하거나, 관리자에게 관리자가 건 중지 풀기를 받는다.**가 붙고 **위험 구역**에 **다시 쓰기**가 없다. 관리자에게 부탁하거나, 관리자가 그 owner에게 **관리자가 건 중지 풀기**를 맡기면(16.7절) owner가 푼다.
- 관리자가 자기가 owner인 스페이스를 중지하면 주인으로서 중지한 것이다.
- 주인이 중지한 스페이스를 관리자가 보면 **관리자가 건 중지로 바꾸기** 단추가 있다(관리 칸의 **위험 구역**과 **스페이스 관리** 화면). 누르면 확인 대화 **관리자가 건 중지로 바꿀까요?** 가 뜨고, **넘겨받는다**를 누르면 관리자가 중지한 스페이스가 된다 — 그 뒤로는 주인도 풀지 못한다. 주인이 다시 쓰지 못하고 Crew도 바꾸지 못하게 얼려 두려면 이것을 누른다.
- 관리자가 중지한 동안에는 owner가 Crew도 바꾸지 못한다 — 관리자만 바꾼다(2.3절).

### 2.6 스페이스 관리 칸

스페이스 첫 화면 아래쪽(팀 스페이스는 **Crew** 칸 다음)에 있는 관리 구획들이다 — 위에서부터 **스페이스 정보**, **분류 관리**, **위험 구역**. 이 문서는 이 셋을 묶어 관리 칸이라 부른다. 팀 스페이스의 owner, 개인 스페이스의 주인, 관리자에게 보인다. **스페이스 관리 전체**를 맡겨 받은 사람이 그 팀 스페이스의 Crew(editor·viewer)이면 **스페이스 정보**·**분류 관리** 없이 **위험 구역**의 **중지**·**다시 쓰기**만(중지된 스페이스면 **지우기**도) 보인다. 스페이스가 중지돼 있으면 관리 칸 맨 위에 누가 중지했는지가 보인다(2.5절).

1. **스페이스 정보**에서 **이름**(필수) · **설명** · **분류**를 고치고 **저장**을 누른다. 그 구획 안에 **저장했다.**가 뜨고 제목 아래 줄에 새 분류가 보인다.
   - 맞는 분류가 없으면 **새 분류** 칸에 이름을 넣고 칸 옆의 **분류 만들기**를 누른다(이 칸의 Enter도 같다). **분류 "재무"을(를) 만들어 골랐다 — 저장을 누르면 붙는다.**가 뜨고 **분류**에 골라진다. 칸 아래 도움말대로 **만든 분류가 위 칸에 골라진다 — 저장을 눌러야 이 스페이스에 붙는다.** 같은 이름이 이미 있으면 새로 만들지 않고 **있던 분류 "재무"을(를) 골랐다 — 저장을 누르면 붙는다.**가 뜬다.
   - 그 아래 **분류 관리**에는 **내가 만들었고** 지금 이름을 바꾸거나 지울 수 있는 분류가 한 줄씩 보인다. 이름 칸을 고치고 **이름 바꾸기**, 또는 **지우기**. 이름 칸 옆에 **공간 2개**처럼 그 분류를 쓰는 스페이스의 수(휴지통 포함)가 보인다. **지우기**는 확인 대화 **분류를 지울까요?** 를 띄우고(0.4절), **지운다**를 누르면 지운다 — 그 분류를 쓰던 스페이스는 분류 없음이 된다.
   - **남의 스페이스가 그 분류를 쓰기 시작하면** 만든 사람도 이름을 바꾸거나 지우지 못한다 — 분류 관리에서 사라진다. 관리자나 **분류 관리**를 맡겨 받은 사람이 한다(17.1절). 없으면 **내가 만들어 이름을 바꾸거나 지울 수 있는 분류가 없다 — 남의 공간이 쓰는 분류는 관리자가 바꾼다.**가 보인다.
2. **위험 구역**의 **중지**를 누르면 확인 대화 **스페이스를 중지할까요?** 가 뜬다. **멈춘다**를 누르면 **중지했다 — 읽기만 된다.** 가 뜨고 모두 읽기만 된다(열어 둔 편집 창은 몇 분 안에 끊긴다 — 2.5절). 중지된 스페이스에서는 **스페이스 정보**의 이름·설명·분류 칸이 잠기고(**새 분류** 줄은 보이지 않는다) **저장** 옆에 **중지된 스페이스는 이름·설명·분류를 바꿀 수 없다. 먼저 다시 쓸 수 있게 한다.**가 보인다 — 먼저 **위험 구역**의 **다시 쓰기**를 누른다(묻지 않는다 — **다시 쓸 수 있게 했다.**). 관리자가 중지해 풀지 못하는 주인에게는 **중지된 스페이스는 이름·설명·분류를 바꿀 수 없다. 관리자가 다시 쓰게 하면 바꿀 수 있다.**가 보인다(2.5절). 관리자가 **주인이 중지한** 스페이스에서 다시 쓰기 → 바꾸기 → 다시 중지를 하면 다시 건 중지는 관리자가 건 것이 된다(주인이 풀지 못하고 Crew도 바꾸지 못한다) — 주인이 풀 수 있게 두려면 다시 쓰기만 하고 주인에게 알린다.
3. **위험 구역**의 **지우기**는 주인에게는 스페이스가 **활성**이고 Crew가 본인뿐일 때(개인 스페이스는 늘 본인뿐이다), 관리자(와 **스페이스 관리 전체**를 맡겨 받은 사람)에게는 **중지된** 스페이스에서 보인다. 중지된 스페이스는 주인도 지우지 못한다 — 관리자(와 **스페이스 관리 전체**를 맡겨 받은 사람)만 지운다. **지우기**가 없을 때는 그 자리에 **지우기는 활성 스페이스에서 Crew가 본인뿐인 주인, 또는 중지된 스페이스에서 관리자(와 스페이스 관리 전체를 받은 사람)가 할 수 있다.** 가 보인다. 누르면 확인 대화 **스페이스를 지울까요?** 가 뜨고, **지운다**를 누르면 지우고 첫 화면(스페이스 목록)으로 간다. 스페이스와 그 안의 페이지가 보이지 않게 되고, 되살리기는 관리자(와 **스페이스 관리 전체**를 맡겨 받은 사람)가 휴지통에서 한다(17.2절). 개인 스페이스는 지우면 화면에서 다시 만들지 못한다(2.2절).

- 누가 언제 바꿨는지는 감사로그 **space.update** · **space.status.change** · **space.delete**에 남는다(18절).

## 3. 페이지

### 3.1 새 페이지 만들기

1. 스페이스를 연다(첫 화면 표의 이름, 또는 왼쪽 칸의 **스페이스 첫 화면**). 제목 아래의 **새 페이지** 구획에서 **새 페이지 제목**(필수)에 제목을 넣는다. 스페이스 안의 어느 화면에서든 왼쪽 칸의 **새 페이지**를 누르면 이 구획으로 오고 커서가 제목 칸에 간다.
2. **위치**에서 어느 페이지 아래에 만들지 고른다. **맨 위**면 맨 위 단계다. 나머지는 **회의록 아래**처럼 보이고, 트리처럼 들여 써 있다.
3. 관리자가 만든 템플릿(문서 틀)이 있으면 **템플릿** 칸이 보인다. 틀을 고르면 그 내용으로 시작하고, **빈 문서로 시작**이면 빈 페이지다.
4. **만들기**를 누르면 곧바로 **페이지 편집** 화면이 열린다(4·5절).

- 새 페이지는 고른 위치의 맨 끝에 생긴다. 보고 있는 페이지 아래에 만들려면 그 페이지의 **하위 페이지 만들기**를 누른다(3.3절).
- 만든 순간이 버전 1이다. 처음 저장하면 버전 2가 된다.
- 쓸 수 없는 스페이스(viewer이거나 중지)에는 이 구획도, 왼쪽 칸의 **새 페이지**도 없다.
- 틀로 만든 페이지는 나중에 그 템플릿이 지워져도 그대로다.

### 3.2 페이지 보기 화면

왼쪽 칸의 페이지 트리(3.3절)에서 제목을 누르면 보기 화면이 열린다. 트리는 보기 화면에서도 그대로 왼쪽에 있어, 다른 페이지를 눌러 곧바로 옮겨 간다.

- 맨 위 줄 왼쪽은 지금 있는 곳(빵부스러기)이다 — **기획팀 공간 / 회의록 / 9월 회의**처럼 스페이스, 상위 페이지들, 이 페이지 순이다. 앞의 이름을 누르면 그 스페이스 첫 화면이나 그 상위 페이지로 간다. 마지막(이 페이지)은 링크가 아니다.
- 같은 줄 오른쪽: **편집** · **하위 페이지 만들기** · **옮기기** · **삭제**. 쓸 수 있는 사람에게만 보인다.
- 그 아래 글 칸에 제목, 그 아래 **버전 5 · 시각 · 이력** 줄(**이력**을 누르면 6절), 그 아래 도구 줄 **HTML로 내보내기** · **텍스트 복사** · **마크다운 복사** · **넓게 보기**(12절·아래)가 있다.
- 그 아래에 본문, 그리고 **라벨**(10절) · **첨부**(8절) · **댓글**(9절) 구획이 차례로 있다. 관리자에게는 맨 아래(댓글 다음)에 접힌 **템플릿** 구획(17.3절)도 보인다.

**넓게 보기** — 글 칸은 읽기 좋은 폭(760px)으로 가운데 놓인다. 표가 넓거나 긴 줄을 한눈에 보려면 도구 줄의 **넓게 보기**를 누른다 — 글 칸이 1200px까지 넓어진다. 한 번 더 누르면 돌아온다.

- 편집 화면의 편집 줄에도 같은 **넓게 보기**가 있고(4절), 보기와 편집·이력의 미리보기가 같은 값을 쓴다 — 보기에서 켜면 편집에서도 넓다. 그래서 편집할 때와 볼 때 줄이 같은 자리에서 바뀐다.
- 켰는지는 이 브라우저가 기억한다. 다른 페이지를 열어도, 다음 날 열어도 그대로다. 다른 PC나 다른 브라우저에서는 처음처럼 좁다(23.1절).

### 3.3 페이지 트리 — 하위 페이지

스페이스 안의 화면(스페이스 첫 화면, 페이지 보기·편집·이력)에서는 왼쪽 칸에 그 스페이스의 페이지 트리가 있다. 어떤 페이지의 하위 페이지는 그 밑에 들여 써서 보인다. 제목 옆의 **v5**는 지금 버전이다. 지금 보고 있는 페이지는 파란 바탕에 굵게 보인다. 페이지가 하나도 없으면 **아직 페이지가 없다.**

- 하위 페이지가 있는 줄 앞에는 화살표 단추가 있다. 누르면 그 아래가 접히고, 한 번 더 누르면 펼쳐진다. 화면을 처음 열면 모두 펼쳐져 있다 — 접은 상태는 페이지 보기끼리 옮겨 다닐 때만 남고, 편집·이력·스페이스 첫 화면으로 가면 다시 모두 펼쳐진다(브라우저가 기억하는 왼쪽 칸 접기와 다르다 — 0.3절).
- 트리가 안 보이면 왼쪽 칸이 접힌 것이다 — 위 막대 맨 왼쪽의 세 줄 모양 단추나 Ctrl+[ 로 편다(0.3절).
- 왼쪽 칸에 **트리를 읽지 못했다.** 가 보이면 서버에 닿지 않았거나 그 스페이스를 볼 수 없게 됐다. **다시 읽기**를 누른다. 계속되면 새로 고친다.

**하위 페이지 만들기** — 페이지 보기 화면의 **하위 페이지 만들기**를 누르면 스페이스 첫 화면의 **새 페이지** 구획으로 가고, **위치**에 그 페이지가 골라져 있고 커서가 제목 칸에 있다. 제목을 넣고 **만들기**를 누른다.

**옮기기** — 페이지 보기 화면의 **옮기기**를 누르면 글 칸 맨 위에 **페이지 옮기기** 구획이 열린다. **옮기기**를 한 번 더 누르거나 구획의 **닫기**를 누르면 닫힌다.

1. **어디 아래로**에서 새 부모를 고른다. **맨 위**면 맨 위 단계다. 칸 아래 도움말대로 **자기 자신과 그 아래로는 옮길 수 없다. 페이지는 10단계까지 들어간다.** — 자기 자신과 그 아래 페이지는 목록에 없다.
2. **자리**에서 형제 가운데 어디에 둘지 고른다 — **맨 앞**, 또는 **○○ 다음**. 부모를 바꾸면 기본은 맨 뒤, 그대로 두면 지금 자리다.
3. 구획의 **옮기기**를 누르면 스페이스 첫 화면으로 가고, 왼쪽 칸의 트리가 새 자리로 그려진다. 하위 페이지는 함께 옮겨진다.

- 페이지는 10단계까지 들어간다. 넘으면 **페이지 트리 깊이는 10를 넘을 수 없다**가 뜨고 옮겨지지 않는다.
- 자리는 **페이지 옮기기** 구획을 연 때의 "형제 가운데 몇 번째"로 보낸다. 구획을 연 뒤 다른 사람이 같은 부모 아래에 페이지를 만들거나 옮기거나 지웠으면 **○○ 다음**이 한 칸 어긋난 자리에 놓일 수 있다 — 옮긴 뒤 트리를 보고, 어긋났으면 한 번 더 옮긴다.
- **이 스페이스의 페이지 트리를 다른 사람이 바꾸는 중이다 — 잠시 뒤 다시 한다**가 뜨면 잠시 뒤 다시 누른다. 같은 스페이스에서 옮기기·만들기·지우기가 한꺼번에 몰리면 차례로 하고, 오래 기다리게 되면 이 말로 돌려보낸다.
- 다른 스페이스로는 옮기지 않는다 — 읽을 수 있는 사람(Crew)이 달라진다. 옮기려면 새 스페이스에 새로 만들고 내용을 붙여 넣는다.
- 누가 언제 옮겼는지는 감사로그 **page.move**에 남는다(18절).

### 3.4 페이지 지우기

1. 페이지 보기 화면 맨 위 줄 오른쪽의 **삭제**를 누른다. 묻지 않고 곧바로 휴지통으로 가고 스페이스 첫 화면으로 돌아간다(휴지통에서 되살리므로 확인 대화가 없다 — 0.4절).
2. 되살리려면 **휴지통**에서 한다(13절).

- 하위 페이지가 달린 페이지는 지울 수 없다. **하위 페이지가 있는 페이지는 삭제할 수 없다. 하위를 먼저 옮기거나 삭제한다**가 뜨면 하위 페이지를 먼저 다른 곳으로 옮기거나(3.3절) 지운다.
- 지운 페이지의 첨부·댓글도 함께 보이지 않게 되고, 페이지를 되살리면 함께 돌아온다.

## 4. 편집기로 쓰기

페이지 보기의 **편집**을 누르면 **페이지 편집** 화면이 열린다. 회색 바탕 위에 흰 종이가 놓인 모양이다.

- 맨 위(위 막대 바로 아래)에 편집 줄이 붙어 있다 — **← 보기로**, 연결 상태(5.4절), **넓게 보기**(3.2절), **쓰는 대로 자동으로 저장된다**, **저장하고 보기로**(5.2절. 실시간 편집이 꺼진 서버에서는 5.5절). 긴 문서를 내려가며 써도 이 줄은 늘 보인다.
- 종이 안에는 위에서부터 지금 있는 곳(**기획팀 공간 / 9월 회의**처럼 스페이스와 이 페이지), **페이지 편집**, **제목** 칸, **본문** 칸이 있다.
- 왼쪽 칸에는 보기 화면처럼 그 스페이스의 페이지 트리가 있다.

본문은 **테두리가 있는 큰 칸**에 쓴다 — 칸 안 어디를 눌러도 글이 들어가고, 누르면 테두리가 파랗게 바뀐다. 칸 위의 **본문**이라는 글자를 눌러도 커서가 본문 칸에 간다. 이 편집기에는 모양을 고르는 단추 모음이 없다. 줄 맨 앞에 기호를 치거나 단축키를 눌러 모양을 낸다. 댓글 칸도 같은 편집기다.

### 4.1 모양 내기

| 모양 | 줄 맨 앞에서 친다 | 단축키 |
|---|---|---|
| 큰 제목 | # 과 빈칸 | Ctrl+Alt+1 |
| 작은 제목(2단계부터 6단계) | ## 부터 ###### 까지와 빈칸 | Ctrl+Alt+2 부터 Ctrl+Alt+6 까지 |
| 글머리 목록 | - 와 빈칸 (+ 와 빈칸도 된다) | Ctrl+Shift+8 |
| 번호 목록 | 1. 과 빈칸 | Ctrl+Shift+7 |
| 목록을 한 단계 안으로, 밖으로 | — | Tab, Shift+Tab |
| 인용 | > 와 빈칸 | Ctrl+Shift+B |
| 코드 블록 | \~\~\~ 과 빈칸 | Ctrl+Alt+C |
| 가로줄 | --- (빼기표 셋) | — |
| 굵게 | — | Ctrl+B |
| 기울임 | — | Ctrl+I |
| 밑줄 | — | Ctrl+U |
| 취소선 | — | Ctrl+Shift+S |
| 글 속의 코드 | — | Ctrl+E |
| 문단을 나누지 않고 줄만 바꾸기 | — | Shift+Enter |

- 모양을 내는 단축키는 한 번 더 누르면 풀린다.
- 줄 맨 앞에 친 기호 때문에 모양이 바뀌었는데 원하지 않았으면 곧바로 Backspace를 누른다. 친 글자로 돌아간다.
- 편집기가 아는 모양은 이 표와 링크(4.2절)·표(4.3절)가 전부다. 글자 색·글자 크기·문단 정렬은 없다.

### 4.2 링크

- http:// 나 https:// 로 시작하는 주소를 치고 빈칸을 치면 링크가 된다.
- 글자를 골라 놓고 주소를 붙여 넣으면(Ctrl+V) 고른 글자가 그 주소의 링크가 된다.
- 위키의 다른 페이지를 가리키려면 그 페이지를 열고 브라우저 주소창의 주소를 통째로 복사해 쓴다(https://wiki.example.internal/pages/ 로 시작한다).
- 이메일 주소(hong.gd@example.internal)는 링크가 되지 않고 글자로 남는다. 다른 곳에서 메일 링크를 붙여 넣어도 글자만 들어간다.
- www 로 시작하는 주소도 링크가 되지 않는다. https:// 를 앞에 붙여 적는다.
- 링크를 누르면 새 탭에서 열린다. 편집 화면에서도 그렇다. 링크 글자 안으로 커서를 옮기려면 화살표 키를 쓴다.
- 링크만 떼는 단추는 없다. 링크 글자를 지우고 다시 친다.

### 4.3 표

- 표를 새로 넣는 단추나 기호가 없다. 다른 곳에서 복사한 표를 본문에 붙여 넣으면 표가 된다. 들어온 표의 칸 안 글자는 그 자리에서 고친다.
- 표 안에서 Tab은 다음 칸, Shift+Tab은 앞 칸으로 간다. 마지막 칸에서 Tab을 누르면 아래에 줄이 하나 생긴다.
- 표를 통째로 지우려면 모든 칸을 끌어서 고른 뒤 Backspace나 Delete를 누른다.
- 칸을 합치거나 열을 더하고 빼는 단추는 없다.

### 4.4 그림

본문에는 그림을 넣을 수 없다. 편집기에 그림 칸이 없다. 그림 파일은 페이지의 **첨부**로 올린다(8절). 다른 곳에서 그림이 섞인 내용을 붙여 넣으면 그림은 빠지고 글만 들어간다.

### 4.5 다른 곳에서 붙여 넣기

- 편집기가 아는 모양(4.1절의 모양과 링크·표)만 남는다. 글자 색·크기, 문단의 가운데 정렬 같은 것은 빠진다.
- 아주 큰 내용을 한 번에 붙여 넣으면 **서버가 이 편집을 받지 않았다**로 시작하는 알림이 뜰 수 있다. 나눠서 붙여 넣는다(5.4절).

### 4.6 되돌리기

- Ctrl+Z로 되돌리고, Ctrl+Y나 Ctrl+Shift+Z로 다시 한다.
- 여럿이 같이 고치는 중이면 되돌리기는 내가 한 것만 되돌린다. 남이 쓴 글은 건드리지 않는다.

## 5. 저장과 같이 고치기

이 위키는 여럿이 같은 페이지를 동시에 고치는 것(실시간 편집)이 기본이다. 편집 화면 맨 위의 편집 줄에 **쓰는 대로 자동으로 저장된다**가 보이고 단추가 **저장하고 보기로**면 실시간 편집이다. 서버에서 실시간 편집을 꺼 두었으면 5.5절처럼 동작한다.

### 5.1 자동 저장

- 치는 글은 곧바로 서버와, 같은 페이지를 보는 사람에게 간다.
- 손을 멈추고 몇 초(기본 5초)가 지나면 그때까지의 내용이 새 버전으로 남는다. 저장 단추를 누르지 않고 창을 닫아도 된다. 마지막 사람이 나가면 서버가 남긴다.
- 커서만 움직였거나 내용이 그대로면 버전이 늘지 않는다.
- 본문을 모두 지운 빈 페이지는 저절로 남기지 않는다. 정말 비우려면 **저장하고 보기로**를 누른다.
- **제목**도 저절로 남는다. 제목 칸에서 손을 멈추고 1초쯤 지나면 서버에 가고, 다음 자동 저장 때 본문과 함께 버전으로 남는다. 1초가 되기 전에 **← 보기로**를 누르거나 창을 닫아도 그때 보낸다.
- 다만 제목은 **같이 보는 사람의 화면에 곧바로 바뀌어 보이지 않는다.** 그 사람의 제목 칸에는 새로고침할 때까지 옛 제목이 그대로 있다.
  그래도 새 제목은 남는다 — 그 사람이 **저장하고 보기로**를 눌러도 자기가 제목 칸을 고치지 않았으면 제목은 보내지 않는다. 두 사람이
  같은 제목을 각자 고치면 나중에 고친 쪽이 남는다.

### 5.2 저장하고 보기로

편집 줄 오른쪽 끝의 **저장하고 보기로**는 지금 내용과 제목을 그 자리에서 버전으로 남기고 보기 화면으로 간다. 누르는 동안 **저장 중…** 이 보인다.

- 고친 것이 없거나 자동 저장이 이미 지금 내용을 남겼으면 새 버전을 만들지 않고 **그대로 보기 화면으로 간다.** 내용은 이미 남아 있다.
- 남기지 못하면 편집 화면에 그대로 있고 편집 줄 바로 아래(종이 위)에 까닭이 뜬다. 쓰던 글은 종이 안에 그대로 있다.

| 화면 | 뜻 | 할 일 |
|---|---|---|
| **저장되지 않았다: 문서 검증 실패 (2건)** 처럼 | 저장할 수 없는 모양이 들어 있다 | 편집 줄 아래 **자동 저장이 멈췄다:** 알림의 까닭을 본다(5.4절) |
| **저장되지 않았다: 편집 중인 사람이 없다** | 서버가 이 편집 연결을 모른다(서버가 다시 켜졌을 때 등) | 쓰던 내용을 복사해 두고 새로고침한다 |
| **저장되지 않았다: 이 화면의 입력이 아직 서버에 닿지 않았다 — 연결이 끊겼을 수 있다. …** | 이 화면에서 친 글자나 **지운 것**이 서버에 가지 않았다 — 연결이 끊겼는데 아직 화면이 모른다. 누르고 1.5초쯤 기다려도 오지 않을 때 뜬다 | 쓰던 내용을 다른 곳에 복사한 뒤 새로고침한다. 그대로 보기로 가면 그 편집은 없다(지운 글은 그대로 남아 있다) |
| **저장되지 않았다: 빈 문서** | 아무것도 쓰지 않은 새 페이지다 | 무엇이든 쓰고 누른다 |
| **저장되지 않았다. 쓰던 내용을 다른 곳에 복사한 뒤 새로고침한다** | 까닭을 알 수 없는 실패다 | 화면이 말하는 대로 한다 |

연결이 끊긴 동안이나 서버가 편집을 받지 않은 동안에는 이 단추가 눌리지 않는다.

### 5.3 여럿이 같이 고치기

- 같은 페이지를 여럿이 열면 서로 치는 글이 곧바로 보인다. 둘이 같은 곳을 고쳐도 둘 다 남는다. 먼저 저장한 사람이 이기는 일이 없다.
- 편집 줄의 **← 보기로** 옆에 **같이 보는 사람: 홍길동, 김영희**처럼 나를 뺀 사람들이 보인다. 아무도 없으면 **같이 보는 사람 없음**.
- 다른 사람의 커서는 색 막대와 이름표로 보인다. 같은 사람은 늘 같은 색이다.
- 자동 저장된 버전의 이력에는 그 판을 마지막으로 고친 사람의 이름이 적힌다.
- 누가 이력에서 옛 버전으로 되돌리면 편집 중인 사람들의 연결이 끊긴다(6.3절).

### 5.4 편집 줄과 그 아래의 알림

연결 상태는 편집 줄의 **← 보기로** 옆에 보인다. 문제가 생기면 편집 줄에 짧은 표지(**연결 끊김** · **자동 저장 멈춤**)가 붙고, 까닭을 말하는 알림은 편집 줄 바로 아래(종이 위)에 뜬다. 긴 문서의 아래쪽을 쓰고 있어 알림이 화면 밖에 있어도 편집 줄의 표지는 보인다 — 표지가 보이면 맨 위로 올라가 알림을 읽는다.

| 화면에 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| **연결 중…** | 서버와 이어지는 중이다 | 잠깐 기다린다 |
| **같이 보는 사람 없음** 또는 **같이 보는 사람:** 으로 시작하는 줄 | 이어졌다. 쓰는 대로 저장된다 | 그대로 쓴다 |
| 편집 줄의 **연결 끊김** | 아래 두 알림(연결이 끊겼다, 서버가 이 편집을 받지 않았다) 가운데 하나가 떠 있다. 이 동안 **저장하고 보기로**는 눌리지 않는다 | 그 알림대로 한다 |
| 편집 줄의 **자동 저장 멈춤** | 아래 **자동 저장이 멈췄다:** 알림이 떠 있다 | 그 알림대로 한다 |
| **연결이 끊겼다. 지금 쓰는 내용은 저장되지 않는다 — 다른 곳에 복사한 뒤 새로고침한다** | 서버와 끊겼다. 로그인이 풀렸거나(1.9절), 이 브라우저에서 로그아웃했거나, 비밀번호를 바꿨거나, 관리자가 세션을 끊었거나, Crew에서 빠졌거나 viewer가 됐거나, 스페이스가 중지됐거나, 누가 옛 버전으로 되돌렸거나, 망이 끊겼다 | 쓰던 내용을 메모장 같은 곳에 복사한다. 새로고침(F5)한 뒤 필요하면 다시 붙여 넣는다. 자주 되풀이되면 관리자에게 알린다 |
| **서버가 이 편집을 받지 않았다. 쓰던 내용을 다른 곳에 복사한 뒤 새로고침한다 — 계속되면 관리자에게 알린다** | 방금 보낸 편집을 서버가 받지 않고 내 연결만 끊었다. 같이 쓰던 사람은 아무 일도 겪지 않는다. 아주 큰 내용을 한 번에 붙여 넣었을 때 생길 수 있다 | 복사한 뒤 새로고침한다. 같은 것을 붙여 넣다 또 끊기면 무엇을 어디서 붙여 넣었는지와 시각을 관리자에게 알린다 |
| **자동 저장이 멈췄다:** 뒤에 까닭, 이어서 **풀리기 전에는 버전이 남지 않는다** | 글은 같이 보는 사람에게 보이지만 버전(이력)이 남지 않는다 | 까닭이 **노드 수 50000 초과**면 문서가 너무 길다. 나눠서 다른 페이지로 옮긴다. 까닭에 textAlign이 보이면 그 문단을 한 번 고친다. **서버가 버전을 남기지 못했다 — 잠시 뒤 다시 한다**면 기다린다. 저절로 다시 한다. 모르겠으면 쓰던 내용을 복사해 두고 관리자에게 알린다 |

### 5.5 실시간 편집이 꺼진 서버에서

관리 담당이 서버에서 실시간 편집을 끄면 편집 화면이 다르게 동작한다. 편집 줄의 **← 보기로** 옆에 **편집을 시작한 버전: v3**처럼 보이고, **쓰는 대로 자동으로 저장된다**가 없으며, 단추 이름이 **저장**이다.

- 저절로 저장되지 않는다. **저장**을 눌러야 남는다.
- 같은 페이지를 다른 사람이 먼저 저장했으면 편집 줄 아래에 **다른 사람이 먼저 저장했다** 알림이 뜨고 **저장**이 눌리지 않는다. 그 안에 **다른 사용자가 먼저 저장했다. 최신 버전을 불러와 다시 편집해야 한다**와 **내가 편집을 시작한 버전 v3 · 현재 서버 버전 v4**가 보인다.
- 덮어쓰는 단추는 없다. 쓰던 내용을 다른 곳에 복사한 뒤 **최신 내용 불러오기**를 누르고 다시 고친다. 화면도 경고한다: **지금 쓴 내용은 사라진다. 필요하면 다른 곳에 복사해 둔 뒤 눌러야 한다.**
- 같은 페이지를 내 브라우저 탭 두 개에서 열어 둬도 이렇게 된다.
- 저장하지 않은 편집이 있는 채 창을 닫거나 새로 고치면 브라우저가 떠날지 묻는다. 왼쪽 칸의 트리나 위 막대로 옮겨 가는 것은 묻지 않고 쓰던 내용이 사라진다 — 먼저 **저장**한다.

## 6. 이력·비교·되돌리기

### 6.1 이력 보기

페이지 보기 제목 아래 **버전 5 · 시각 · 이력** 줄의 **이력**을 누르면 **버전 이력** 화면이 열린다. 제목 위에 지금 있는 곳(스페이스 / 페이지), 제목 오른쪽에 **← 보기로**가 있고, 제목 아래에 **복원해도 이력은 지워지지 않는다. 그 내용으로 새 버전이 하나 더 생긴다.** 가 있다. 왼쪽 칸은 그 스페이스의 페이지 트리다.

버전 목록은 버전마다 **v3**, 그때의 제목, 고친 사람, 시각이 한 줄이고, 그 뒤에 **비교** 칸, **보기**, **이 버전으로 복원**이 있다. **이 버전으로 복원**은 쓸 수 있는 사람에게만 보인다.

**보기**를 누르면 목록 위(**비교하기** 줄 아래)에 **v3 미리보기**가 열린다. 비교 결과(6.2절)와 미리보기는 같은 자리를 번갈아 쓴다 — 하나를 열면 다른 하나는 닫힌다.

### 6.2 두 버전 비교

1. 목록에서 **비교** 칸 두 개에 표시한다. 목록 위 **비교하기** 단추 옆에 **아래 목록에서 두 개를 고르면 무엇이 바뀌었는지 볼 수 있다. 지금 고른 것: v2, v5** 처럼 보인다(고르기 전에는 **없음**). 셋째를 고르면 가장 먼저 고른 것이 풀린다.
2. **비교하기**를 누른다. 두 개를 골라야 눌린다.
3. 목록 위 상자의 맨 위 줄에 **v2 → v5 · 변경 1 · 추가 2 · 삭제 0**처럼 개수가 나온다. 제목도 바뀌었으면 **제목도 바뀌었다**가 붙는다. 번호가 작은 버전에서 큰 버전으로 견준다.
4. 그 아래에 문단마다 표시가 붙는다.

| 표시 | 뜻 |
|---|---|
| 왼쪽 초록 막대와 + | 새로 생긴 문단 |
| 왼쪽 빨간 막대와 −, 줄이 그어진 글 | 없어진 문단 |
| 왼쪽 노란 막대와 \~ | 고쳐진 문단. 그 안에서 새로 생긴 낱말은 초록 바탕, 없어진 낱말은 빨간 바탕에 줄이 그어진다 |
| 흐린 글자 | 바뀌지 않은 문단 |

두 버전의 내용이 같으면 **두 버전의 내용이 같다.**

### 6.3 옛 버전으로 되돌리기

- **이 버전으로 복원**을 누르면 묻지 않고(0.4절) 그 버전의 내용으로 새 버전이 하나 더 생기고 보기 화면으로 간다. 이력은 지워지지 않는다. v1으로 되돌리면 v1의 내용으로 새 번호가 생긴다. 되돌린 것을 다시 되돌릴 수도 있다.
- 누가 그 페이지를 편집하고 있을 때 되돌리면, 편집하던 사람들의 연결이 끊기고 마지막 버전 뒤에 쓴 것은 남지 않는다. 끊긴 화면에서 복사해 두면 살릴 수 있다. 같이 쓰는 페이지라면 편집을 마치게 한 뒤 되돌린다.

## 7. 검색

1. 위 막대의 **검색**을 누른다. 제목 아래에 **볼 수 있는 스페이스의 페이지에서 제목과 본문을 찾는다.** 가 있다.
2. **찾을 말** 칸(안내 **두 글자부터 찾는다**)에 넣고 **찾기**를 누른다(Enter도 같다).
3. **'회의' 결과 12건**처럼 찾은 말과 수가 제목으로 붙고 그 아래에 결과가 나온다. 제목을 누르면 그 페이지가 열린다. 제목 옆에 스페이스 이름이, 그 아래에 찾은 말 앞뒤를 잘라 낸 한 토막이 보인다.

- 제목과 본문에서 그 글자가 들어간 곳을 찾는다. 낱말 가운데 들어 있어도 찾고, 영문 대소문자는 가리지 않는다.
- 최근에 고친 페이지부터 20건까지 나온다. 많으면 찾을 말을 더 길게 쓴다.
- 볼 수 없는 스페이스의 페이지와 휴지통의 페이지는 나오지 않는다. 댓글과 첨부 파일 안의 글은 찾지 않는다.
- 하나도 없으면 **찾은 것이 없다.** 와 그 아래 **볼 수 없는 스페이스의 페이지는 결과에 나오지 않는다.**
- 찾는 칸은 이 화면에만 있다. 위 막대에는 찾는 칸이 없고 **검색**이 이 화면으로 온다.
- 검색 화면의 주소에 찾을 말이 들어 있다. 그 주소를 건네면 받은 사람도 같은 말로 찾은 결과를 본다. 그 사람이 볼 수 있는 것만 나온다.

## 8. 파일 첨부

페이지 보기에서 **라벨** 아래의 **첨부** 구획.

- 올리기: 쓸 수 있는 사람에게 목록 아래 **첨부할 파일** 칸이 있다. 파일을 고르면 곧바로 올라간다. 올라가는 동안 칸 아래에 **올리는 중…** 이 보인다. 한 번에 한 파일이다.
- 목록: 표의 열은 **파일** · **크기** · **올린 사람**이다. 파일 이름을 누르면 내려받는다. 없으면 **첨부가 없다.**
- 지우기: 쓸 수 있는 사람에게 줄 끝의 **삭제**가 보인다. 누르면 확인 대화 **이 첨부를 지울까요?** 가 뜨고(0.4절), **지운다**를 누르면 지운다. 지운 첨부는 화면에서 되살릴 수 없다.
- 받는 파일(기본): pdf, png, jpg, jpeg, gif, webp, txt, csv, md, zip, docx, xlsx, pptx, hwp. 관리자는 이 가운데 일부를 끌 수 있고, 목록 밖의 종류를 더할 수는 없다.
- 크기: 파일 하나에 20MB까지(기본).
- 이름만 바꾼 파일은 막힌다. 파일 앞부분을 읽어 정말 그 종류인지 본다. 빈 파일도 올릴 수 없다.
- 누가 무엇을 올리고 내려받았는지 감사로그에 남는다(감사 기록 단계가 **1 · 최소**면 내려받은 일은 남지 않는다 — 18.3절).
- 안 올라갈 때 뜨는 말은 25절에 있다.

## 9. 댓글

댓글은 페이지 아래의 **댓글 쓰기** 칸(테두리가 있는 상자)에 쓴다.

페이지 보기에서 **첨부** 아래의 **댓글** 구획(관리자에게는 그 아래에 **템플릿**이 하나 더 있다). 제목 옆에 댓글 수가 보이고, 없으면 **댓글이 없다.** 댓글마다 쓴 사람과 시각이 위에 있다.

1. **댓글 쓰기** 아래 칸에 쓴다. 본문과 같은 편집기라 4절의 모양을 쓸 수 있다. **등록**을 누른다.
2. 남의 댓글에 답하려면 그 댓글의 **답하기**를 누른다. 칸 이름이 **답 쓰기**로 바뀌고 **답하는 중 · 취소**가 보인다. 쓰고 **등록**, 그만두려면 **취소**.
3. 답에는 다시 답할 수 없다. 한 단계까지다.

- **삭제**는 쓴 사람, 그리고 그 스페이스에 쓸 수 있는 사람에게 보인다. 누르면 확인 대화 **이 댓글을 지울까요?** 가 뜨고(0.4절), **지운다**를 누르면 지운다. 화면에서 되살릴 수 없다. 답이 달린 댓글이면 대화가 **달린 답 2개도 보이지 않게 된다.** 처럼 함께 알린다.
- 댓글을 고치는 단추는 없다. 지우고 다시 쓴다.
- 댓글에 @아이디를 적으면 그 사람을 부른다(11절).
- viewer는 읽기만 한다.

## 10. 라벨

페이지 보기에서 본문 바로 아래의 **라벨** 구획. 라벨은 이름표처럼 한 줄에 늘어선다. 없으면 **라벨이 없다.**

- 붙이기: **라벨 붙이기** 칸(안내 **예: 회의록**)에 이름을 쓰고 **붙이기**를 누른다.
- 떼기: 라벨 옆의 **떼기**. 묻지 않고 곧바로 뗀다 — 다시 붙이면 된다(0.4절).
- 라벨 이름을 누르면 **라벨: 회의록** 화면에 그 라벨이 붙은 페이지가 모인다(제목 아래 **이 라벨이 붙은 페이지 3건**처럼 수가 보인다). 줄마다 제목과 스페이스 이름이다. 내가 볼 수 있는 것만 나온다. 하나도 없으면 **이 라벨이 붙은 페이지가 없다.**
- 영문은 소문자로 바뀌어 저장된다. 40자까지다. 어느 페이지에도 붙어 있지 않게 된 라벨은 사라진다.
- 쓸 수 있는 사람만 붙이고 뗀다.

## 11. 부르기·알림함·메일

### 11.1 부르기(@멘션)

본문이나 댓글에 @ 다음 아이디를 적으면 그 사람의 알림함에 알림이 간다. 예: @hong.gd 확인 부탁한다.

- 이름이 아니라 아이디다. 아이디는 팀 스페이스 첫 화면의 **Crew** 표에서 **아이디** 열에 보인다.
- @ 앞은 줄의 처음이거나 빈칸·여는 괄호·따옴표여야 한다. 그래서 메일 주소 hong.gd@example.internal의 @는 부르기가 아니다. @hong.gd님처럼 뒤에 조사를 붙여도 된다.
- 언제 가나: 댓글은 **등록**할 때 간다. 본문은 그 내용이 버전으로 남을 때(자동 저장이나 저장 단추) 간다. 앞 버전에 이미 있던 부름은 다시 가지 않는다.
- 가지 않는 경우: 그 스페이스를 볼 수 없는 사람(개인 스페이스라면 주인과 관리자 말고는 누구도), 없는 아이디, 승인 전 계정, 정지된 계정, 나 자신.
- 편집기는 부름을 따로 표시하지 않는다. 알림이 갔는지는 받은 사람에게 확인한다.

### 11.2 알림함

- 모든 화면의 **위 막대 오른쪽**에 **알림** 단추가 있다. 안 읽은 것이 있으면 옆에 빨간 수가 붙는다. 이 수는 화면을 옮길 때와 30초마다 다시 센다.
- 단추를 누르면 **최근 알림** 다섯 건이 펼쳐진다. 줄마다 시각 뒤에 **· 안 읽음** 또는 **· 읽음**이 붙고, 안 읽은 것은 왼쪽에 파란 띠도 있다. **알림함에서 모두 보기**를 누르면 **알림함** 화면으로 간다. 바깥을 누르거나 Esc를 누르거나 다른 화면으로 가면 닫힌다.
- **알림함** 화면은 왼쪽 칸 **바로가기**의 **알림함**으로도 연다. 제목 아래에 **안 읽은 것 2건**이, 오른쪽에 **모두 읽음**이 있다(안 읽은 것이 있을 때만). 알림이 하나도 없으면 **알림이 없다.** 와 **문서나 댓글에서 누가 부르면 여기에 온다.**
- 한 줄에 **홍길동님이 불렀다 · 페이지 제목**, 그 옆에 시각과 **· 안 읽음**(읽은 것은 **· 읽음**)이 있고, 안 읽은 줄 끝에는 **읽음** 단추가 있다. 안 읽은 줄은 왼쪽에 파란 띠가 있다. 제목을 누르면 그 페이지로 간다. 댓글에서 불렀어도 페이지로 간다.
- 페이지를 열어도 읽음이 되지는 않는다. **읽음**이나 **모두 읽음**을 누른다.
- 이름 대신 **문서에서 불렸다**나 **댓글에서 불렸다**가 보이면 누가 불렀는지 확실하지 않은 것이다. 여럿이 같이 고친 문서에서 그 부름을 누가 썼는지 확실하지 않으면 이름을 지어내지 않고 비운다.
- 제목 대신 **(지워진 글)** 이 보이면 그 글이 지워졌거나 지금은 내가 볼 수 없다. 알림은 남는다.
- 관리자와 시스템 관리자에게는 **홍길동 (hong)님의 아이디·email로 비밀번호 초기화가 요청됐다 — 본인에게 확인한 뒤 초기화한다** 도 온다. 아이디와 email만 알면 누구나 남길 수 있는 요청이라 본인이 보냈다고 말하지 않는다. 그 뒤의 **사용자 관리에서 초기화**를 누르면 찾기 칸에 그 아이디가 들어간 사용자 관리로 간다(16.5절). 관리자에서 내려가면 이 알림은 보이지 않는다.
- 최근 것부터 200건까지 보인다. 알림을 지우는 단추는 없다.

### 11.3 메일

서버에서 메일을 켜 두었으면 불린 사람에게 메일도 간다. email이 등록된 사람에게만 간다.

- 제목은 **[위키] 홍길동 님이 회원님을 불렀습니다**이다. 부른 사람을 모르면 **[위키] 문서에서 회원님이 불렸습니다**이다.
- 본문에 글 내용은 없다. 문서와 댓글 가운데 어디서 불렸는지, 문서 제목, 그리고 서버에 위키 주소가 설정돼 있으면 바로 가기 주소가 있다. 내용은 위키에서 본다.
- 메일이 오지 않아도 알림함에는 남는다. 메일이 오지 않으면 관리자에게 알린다(장애 대응 7.21절).

## 12. 내보내기와 복사

### 12.1 HTML로 내보내기와 PDF

- 페이지 보기 도구 줄(제목 아래)의 **HTML로 내보내기**를 누르면 그 페이지가 웹 페이지 파일 하나(페이지 제목.html)로 내려온다. 지금 버전의 내용이다.
- 파일 맨 위에 제목이, 그 아래에 **공간:** 으로 시작해 버전과 **내보낸 시각:** 이 이어지는 줄이 적힌다.
- 인터넷 없이 그대로 열린다. 보관하거나 전달할 때 쓴다.
- PDF가 필요하면 내려받은 파일을 브라우저로 열고 인쇄(Ctrl+P) 화면에서 PDF로 저장을 고른다. 브라우저마다 이름이 조금 다르다. 종이에는 링크 옆에 그 주소가 함께 찍힌다.
- 내보낸 일은 감사로그에 남는다(감사 기록 단계가 **1 · 최소**면 남지 않는다 — 18.3절).

### 12.2 텍스트 복사·마크다운 복사

- 둘 다 페이지 보기의 도구 줄에 있다. **텍스트 복사**는 제목과 본문의 글자만 복사한다. 누르면 단추 옆에 **텍스트를 복사했다**가 보인다.
- **마크다운 복사**는 제목·목록·표 같은 모양을 기호로 적어 복사한다. 누르면 **마크다운을 복사했다**가 보인다.
- 다른 문서나 사내 LLM 질문(14.7절)에 붙여 넣는다. 복사는 감사로그에 남지 않는다.
- **복사하지 못했다 — 브라우저가 클립보드를 막았다**가 뜨면 브라우저가 복사를 허락하지 않은 것이다. 본문을 직접 골라 Ctrl+C로 복사한다.

## 13. 휴지통

1. 위 막대의 **휴지통**을 누른다. 제목 아래에 **지운 페이지와 스페이스는 보존 기간이 지나면 영영 지워진다. 그 전에는 되살릴 수 있다.** 가 있다.
2. **지운 페이지** 목록에서 되살릴 줄 끝의 **되살리기**를 누른다. 줄마다 제목, 그 옆에 스페이스 이름 · **지운 사람 홍길동** · 지운 시각이 보인다. 묻지 않는다(되돌리는 쪽의 일이다).
3. 화면 위에 **"회의록"을 되살렸다.** 가 뜨고 페이지가 원래 자리로 돌아간다.

- 부모 페이지가 아직 휴지통에 있거나, 제자리로 돌아가면 10단계를 넘으면(지운 뒤 부모가 더 깊이 옮겨졌다) 맨 위 단계로 올려 되살리고, 알림 끝에 **제자리로 돌아갈 수 없어(부모가 아직 휴지통에 있거나 10단계를 넘는다) 맨 위로 옮겼다.** 가 붙는다. 나중에 부모를 되살려도 다시 밑으로 들어가지 않는다.
- 내가 쓸 수 있는 스페이스의 페이지만 보인다. viewer에게는 **되살릴 페이지가 없다.** 가 보인다. 중지된 스페이스의 페이지도 보이지 않는다.
- 지운 뒤 보관 기간(기본 30일)이 지나면 영구히 지워질 수 있다. 관리 담당이 정리할 때 지워진다.
- 휴지통에는 페이지만 온다. 지운 첨부·댓글은 여기서 되살릴 수 없다.
- 관리자와 **스페이스 관리 전체**를 맡겨 받은 사람에게는 **지운 페이지** 아래에 **지운 스페이스** 구획도 있다(17.2절).

## 14. 사내 LLM에게 묻기

사내 LLM은 회사 안에 따로 둔 AI 서버다. 질문은 위키 서버를 거쳐 그 서버로 가고, 내 브라우저가 그 서버에 직접 가지 않는다. 관리자가 등록해 두어야 쓸 수 있다.

### 14.1 묻기

1. 위 막대의 **LLM 질문**을 누른다. 왼쪽 칸에 **새 대화** 단추, **내 지시문**, 대화 목록(**고정** · **최근**)이, 본문에 대화가 있다. 새 대화에서는 **아직 주고받은 말이 없다** 가 보인다.
2. 새 대화에서 질문 칸 위의 **지시문**(14.5절. 고르지 않으면 **(없음)**)과 **LLM**(**사내 Qwen · Qwen/Qwen3-32B** 처럼 LLM 이름과 모델)을 고른다.
3. **질문** 칸에 쓰고 **보내기**를 누르거나 Ctrl+Enter를 누른다. Enter만 누르면 줄이 바뀐다.
4. 답은 다 쓰이기를 기다리지 않고 쓰이는 대로 흘러나온다. 끝나면 대화가 저장되고 왼쪽 칸의 **최근**에 생긴다. 대화 제목은 첫 질문의 첫 줄에서 따온다.

- 모델이 답하기 전에 생각을 먼저 적으면 **생각 과정 (저장하지 않는다)** 로 접혀 보인다. 저장되지 않고 다음 질문에도 들어가지 않는다.
- 답마다 **답 복사**가 있다. 누르면 **답을 복사했다**가 보인다.
- 한 사람은 한 번에 하나만 묻는다. 다른 탭에서 답을 받는 중이면 **이미 답을 받고 있다 — 끝나거나 중지한 뒤에 묻는다**가 뜬다.
- 등록된 LLM이 없으면 **등록된 LLM이 없다 — 시스템 관리자에게 등록을 요청한다.**
- 질문 칸에는 10만 자까지 들어간다. 더 긴 글을 붙여 넣으면 넘는 부분이 잘린다.
- 내 대화는 나만 본다. 관리자도 볼 수 없다. 감사로그에는 물었다는 사실과 크기만 남고 내용은 남지 않는다(감사 기록 단계가 **1 · 최소**면 물었다는 사실도 남지 않는다 — 18.3절).

### 14.2 답을 기다릴 때

- 답의 첫 글자가 오기 전까지 **답변을 기다리고 있습니다 · 3s**처럼 기다린 초가 보인다. 5초가 지나면 **답변이 늦어지고 있습니다.** 가 함께 보인다. 사내 LLM 서버가 붐빌 때 그렇다. 기다린다.
- 첫 글자가 오면 이 표시는 사라진다.
- 답 위에는 모델 이름과 **보내는 중…** · **답을 받는 중…** · **멈추는 중…** 가운데 하나가 보인다.

### 14.3 멈추기

- 답을 받는 동안 **중지**가 보인다. 답이 흘러나오기 시작해야 눌린다. 옆에 **페이지를 떠나도 멈춘다 — 받은 데까지 저장한다**가 있다.
- 누르면 **중지했다 — 거기까지 저장했다**가 뜨고 그 답에 **중지됨**이 붙는다. 받은 글자가 없었으면 **중지했다 — 답에 글자가 없어 저장하지 않았다**가 뜨고 질문이 입력칸으로 돌아온다.
- 답을 받다가 다른 화면으로 가거나 뒤로 가기를 눌러도 멈춘다. 받은 데까지는 저장된다.
- 답을 받는 동안에는 왼쪽 칸의 다른 대화와 **새 대화**, 대화 목록의 **고정**·**지우기**가 눌리지 않는다.
- 답이 중간에 끊기면 그 답에 **끊김**이 붙고 까닭이 질문 칸 위의 오류 알림띠로 뜬다(26절). 저장되지 못한 질문은 입력칸으로 돌아온다. 다시 보내면 된다.

### 14.4 이어 묻기와 새 대화

- 왼쪽 칸 대화 목록의 대화를 누르면 그 대화가 열린다. 화면 제목 **LLM 질문**과 안내 아래에 대화 제목과 **지시문: 세 줄 요약**(없으면 **지시문: (없음)**, 고정한 대화면 뒤에 **· 고정**)이 보인다. 거기서 보내면 앞의 질문과 답을 이어서 묻는다.
- 새로 시작하려면 왼쪽 칸의 **새 대화**를 누른다. 지시문은 새 대화를 시작할 때만 고른다 — 이어 묻는 대화에는 **지시문** 칸이 없다. 화면 제목 아래 안내도 그렇게 말한다: **사내 LLM에 묻는다. 지시문은 새 대화를 시작할 때 고르고, 이어 묻는 대화는 시작할 때의 지시문을 쓴다.**
- 대화 하나에 메시지는 200개까지다. 넘으면 **대화 하나에 메시지는 200개까지다 — 새 대화를 시작한다**가 뜬다.
- 대화가 길어 모델이 한 번에 읽지 못하면 **대화가 모델이 한 번에 읽을 수 있는 길이를 넘었다 — 새 대화를 시작한다**로 시작하는 말이 뜬다. 새 대화를 열고 앞 대화의 요점을 붙여 넣는다.
- 그 대화의 LLM이 지워졌으면 다른 LLM을 골라 이어 묻는다.

### 14.5 내 지시문

지시문은 LLM에게 늘 먼저 주는 말이다(예: 세 줄로 요약한다).

1. 왼쪽 칸의 **내 지시문**을 누른다. LLM 질문 화면의 왼쪽 칸에도, 첫 화면 같은 다른 화면의 왼쪽 칸 **바로가기**에도 있다. **내 지시문** 화면에서도 왼쪽 칸은 **새 대화**·**내 지시문**·대화 목록이다(목록은 보기만 한다 — 고정·지우기는 LLM 질문 화면에서).
2. **새 지시문** 구획에 **이름**(필수)과 **지시**(필수)를 쓰고 **저장**을 누른다. **"세 줄 요약"을(를) 저장했다** 가 뜨고, 그 아래에 지시문마다 카드가 하나씩 생긴다.
3. 새 대화에서 **지시문** 칸으로 고른다.

- 제목 아래 안내에 **LLM에 늘 먼저 주는 말이다(시스템 프롬프트). 새 대화를 시작할 때 고른다. 3/50개.** 처럼 지금 가진 수가 보인다.
- 고치려면 그 카드의 **고치기**를 누른다. 카드가 **세 줄 요약 고치기** 구획으로 바뀐다. 고치고 **고친 것 저장**을 누른다(**고쳤다 — 이제부터 시작하는 대화에 쓰인다**). 그만두려면 **그만두기**. 이미 시작한 대화는 시작할 때의 지시문으로 이어진다.
- 카드의 **지우기**는 확인 대화 **이 지시문을 지울까요?** 를 띄운다(0.4절). **없앤다**를 누르면 지운다 — 되살릴 수 없다. 그 지시문으로 시작한 대화는 그대로다.
- 한 사람이 50개까지 가진다. 이름은 겹칠 수 없다(**같은 이름의 지시문이 이미 있다**).
- 지시문은 지울 때까지 남는다. 하나도 없으면 **아직 지시문이 없다.**
- **지시** 칸 아래 도움말대로, Qwen3 모델은 지시문에 /no\_think를 적으면 생각 과정 없이 바로 답한다. 모델에 따라 다르다.

### 14.6 대화는 얼마나 남나

왼쪽 칸의 대화 목록 맨 위에 **고정 3/20 · 보관 42/100 · 고정하지 않은 대화는 마지막 사용 뒤 7일이 지나면 지워진다**처럼 보인다. 숫자는 기본값이고 관리자가 바꾼다.

| 규칙 | 기본값 |
|---|---|
| 고정하지 않은 대화는 마지막으로 물은 뒤 이만큼 지나면 지워진다 | 7일 |
| 한 사람이 가질 수 있는 대화 수(고정 포함) | 100개 |
| 고정할 수 있는 수 | 20개 |

- **최근** 묶음(고정하지 않은 대화)의 대화 이름 아래에 작은 글씨로 **5일 뒤 지워짐** 또는 **오늘 지워짐**이 보인다. 고정한 대화는 **고정** 묶음에 있고 날이 붙지 않는다. 묶음이 비어 있으면 **없다**.
- 대화 옆의 **고정** 단추를 누르면 그 대화가 **고정** 묶음으로 옮겨 가고 풀 때까지 지워지지 않는다. 고정한 대화 옆의 **풀기**를 누르면 그때부터 다시 날을 센다. 고정이 가득 차면 단추가 눌리지 않고, 마우스를 올리면 **고정은 20개까지다 — 하나를 풀고 고정한다**가 보인다.
- 대화 수를 넘으면 새 대화를 저장할 때 고정하지 않은 것 가운데 가장 오래된 것부터 지워지고 **보관 상한을 넘어 오래된 대화 2개를 지웠다**처럼 알린다.
- 대화 옆의 **지우기**는 확인 대화 **이 대화를 지울까요?** 를 띄운다(0.4절). **없앤다**를 누르면 지운다 — 되살릴 수 없다. 열어 둔 대화를 지우면 새 대화로 돌아간다.
- 지웠거나 기간이 지난 대화는 되살릴 수 없다. 옛 주소로 열면 **대화를 찾을 수 없다 — 지웠거나 보존 기간이 지났다**가 뜬다.

### 14.7 위키 페이지를 붙여 묻기

1. 페이지 보기에서 **텍스트 복사**나 **마크다운 복사**를 누른다(12.2절).
2. **LLM 질문**의 **질문** 칸에 붙여 넣고(Ctrl+V), 부탁할 말을 덧붙인다(예: 이 문서를 세 줄로 요약해 줘).
3. **보내기**를 누른다.

- 질문 칸 아래 도움말도 같은 말을 한다: **Ctrl+Enter로 보낸다(Enter는 줄 바꿈). 위키 페이지의 '텍스트 복사'·'마크다운 복사'로 가져온 내용을 붙여 넣어도 된다.**
- 위키가 페이지를 LLM에 몰래 보내는 길은 없다. 내가 붙여 넣은 것만 간다.
- 표나 목록이 있는 페이지는 **마크다운 복사**가 모양을 지켜 준다.
- 답을 위키에 옮기려면 **답 복사**를 누르고 페이지 편집 화면에 붙여 넣는다.

# 2부 관리자 (admin·root)

## 15. 관리 메뉴와 관리자가 더 보는 것

- 위 막대에 **관리**가 보인다. 누르면 **사용자 관리**가 열리고, 관리 화면의 왼쪽 칸 **관리** 묶음에 **사용자 관리** · **감사로그** · **스페이스 관리** · **운영 설정**이, root와 맡겨 받은 admin에게는 **LLM 연결**도 보인다(0.3절). 첫 화면·검색·휴지통 같은 다른 화면의 왼쪽 칸에도 같은 **관리** 묶음이 있다.
- 로그아웃(과 비밀번호로 로그인하는 계정이면 비밀번호 변경)은 관리 화면에서도 위 막대 오른쪽에 있다(0.3절).
- 관리자는 Crew가 아니어도 모든 스페이스를 읽고 쓴다. 중지된 스페이스는 관리자도 읽기만 한다.
- **검색**에는 모든 스페이스의 페이지가 나온다. **휴지통**에는 모든 스페이스(중지된 것은 빼고)의 지운 페이지와 **지운 스페이스**가 보인다.
- 페이지 보기 맨 아래(댓글 다음)에 접힌 **템플릿** 구획이 보인다(17.3절).
- 관리자가 아니면 이 메뉴가 보이지 않고, 주소를 직접 쳐도 **권한이 없다**로 시작하는 말이 뜨며 막힌다. 다만 **스페이스 관리 전체**나 **분류 관리**를 맡겨 받은 member에게는 위 막대의 **관리**와 왼쪽 칸의 **스페이스 관리**가 보인다 — 그 사람의 **관리**는 **스페이스 관리**를 연다(17.1절).

## 16. 사용자 관리

### 16.1 목록 읽기 — 찾기·상태·더 보기

**사용자 관리** 화면의 제목 아래에 **가입을 승인하고, 역할·위임을 바꾸고, 잠금·정지·세션을 다룬다.** 가 있고, 그 아래 거르기 줄에 **찾기** 칸(안내 **아이디·이름·email**)과 **상태** 고르기, 줄 오른쪽 끝에 **전체 312명 · 100명 보는 중**처럼 수가 보인다.

- **찾기**: 아이디·이름·email의 일부를 넣으면 입력을 멈추고 잠깐 뒤 목록이 바뀐다. 찾기 단추는 없다. 영문 대소문자는 가리지 않는다.
- **상태**: **전체** · **승인 대기** · **활성** · **잠김** · **정지** 가운데 고른다. 찾기와 함께 쓸 수 있다.
- 목록은 가장 최근에 만든 계정부터 **100명씩** 나온다. 더 있으면 표 아래에 **더 보기**가 생기고, 누르면 다음 100명이 이어 붙는다.

표는 **아이디** · **이름** · **역할** · **상태** · **위임** · **조치**다. 맞는 사람이 없으면 표 안에 **찾는 조건에 맞는 사람이 없다.**

| 상태 칸 | 뜻 |
|---|---|
| **승인 대기** | 가입을 요청했고 아직 승인하지 않았다(16.2절) |
| **활성** | 쓸 수 있다 |
| **잠김** | 비밀번호를 여러 번 틀려 잠겼다(16.4절) |
| **정지** | 관리자가 정지했다. 로그인하지 못한다(16.10절) |

- 조치 단추와 역할 칸은 **정지**만 빼고 모두 묻지 않고 곧바로 한다.

### 16.2 가입 승인

- 상태가 **승인 대기**인 줄의 **승인**을 누르면 **활성**이 된다. 그 사람의 개인 스페이스가 생긴다.
- 승인을 기다리는 사람만 보려면 **상태**에서 **승인 대기**를 고른다.
- 가입 요청이 들어와도 알림이 오지 않는다. 가끔 목록을 보거나 감사로그의 **행위**에서 **가입 요청 (user.signup)** 을 고른다(18.2절).
- 거절하거나 지우는 단추는 없다. 승인하지 않으면 그대로 승인 대기로 남는다.

### 16.3 역할 바꾸기

**역할** 칸에서 **시스템 관리자 (root)** · **관리자 (admin)** · **일반 사용자 (member)** 가운데 고르면 곧바로 바뀐다(묻지 않는다). 그 사람의 다음 요청부터 먹는다.

- admin은 root를 줄 수 없다: **'root' 역할을 부여할 권한이 없다**
- 자기 역할은 바꿀 수 없다: **자기 자신의 역할은 바꿀 수 없다**
- 마지막 root는 내릴 수 없다: **마지막 root는 강등할 수 없다**
- admin이 member가 되면 맡겨 둔 LLM 연결 관리가 사라진다(16.7절).
- 사내 계정으로 들어오는 사람은 로그인할 때마다 회사 그룹 정보로 역할이 다시 정해진다. 여기서 바꿔도 다음 로그인에 돌아간다(16.9절).

### 16.4 잠금 해제

상태가 **잠김**인 줄의 **잠금 해제**를 누른다. 기다려도 저절로 풀린다(기본 15분).

### 16.5 비밀번호 초기화 — 초기화 요청 처리

사용자가 **비밀번호 찾기**(1.6절)로 요청을 남겼거나 비밀번호를 잊었다고 연락해 오면:

1. 요청은 **알림**으로 온다 — 그 사람을 관리할 수 있는 관리자와 시스템 관리자 모두에게(11.2절). **홍길동 (hong)님의 아이디·email로 비밀번호 초기화가 요청됐다 — 본인에게 확인한 뒤 초기화한다** 옆의 **사용자 관리에서 초기화**를 누르면 찾기 칸에 그 아이디가 들어간 사용자 관리가 열린다. 알림은 넣은 아이디와 email이 실제 계정과 맞을 때만 온다. 맞지 않은 요청까지 보려면 감사로그에서 행위를 **비밀번호 초기화 요청 (auth.password.recover)** 로 고른다(18.2절) — **대상** 칸 둘째 줄이 그 사람이 넣은 아이디이고, **상세**의 found가 true면 맞았다는 뜻이다.
2. 요청한 사람이 정말 그 계정의 주인인지 확인한다. 화면이 약속한 대로 관리자가 확인하고 초기화한다.
3. **사용자 관리**에서 그 줄의 **비밀번호 초기화**를 누른다. 확인 대화(0.4절) **이 사용자의 비밀번호를 초기화할까요?** 가 뜬다 — 세션이 끊기고 임시 비밀번호는 한 번만 보인다는 것, 요청을 받고 하는 것이면 본인이 요청했는지 먼저 확인하라는 것이 적혀 있다. **새로 만든다**를 누르면 바뀐다.
4. 화면 위(제목 아래)에 **임시 비밀번호 · hong** 처럼 아이디가 붙은 주의 알림띠가 뜨고, 그 안의 상자에 임시 비밀번호가 보인다. **이 값은 다시 볼 수 없다. 지금 전달한다.** 그 자리에서 전하고 **닫기**를 누른다.

- 초기화하면 그 사람의 로그인이 모두 풀리고 열어 둔 편집 화면도 끊긴다. 잠금도 함께 풀린다.
- 그 사람은 임시 비밀번호로 들어와 새 비밀번호를 정한다(1.4절).
- 사내 계정 사용자는 초기화할 수 없다: **사내 IdP 계정이다. 비밀번호를 부여하지 않는다 — IdP로 로그인한다**
- 임시 비밀번호를 잃었으면 한 번 더 초기화한다.
- 누가 초기화하면 그 사람의 요청 알림은 받은 사람 모두에게서 **읽음**이 된다 — 둘이 같은 요청을 받아 둘 다 초기화하면 먼저 전한 임시 비밀번호가 쓸모없어진다.
- 같은 사람이 여러 번 요청해도 읽지 않은 요청 알림이 있으면 새로 오지 않는다. 읽은 뒤에 또 요청하면 다시 온다.

### 16.6 세션 강제 종료

그 줄의 **세션 강제 종료**를 누르면 **홍길동님의 세션 2개를 끊었다.** 가 뜬다. 세션은 로그인해 있는 상태 하나다(브라우저마다 하나).

- 그 사람의 로그인이 모두 끝나고, 열어 둔 편집 화면이 그 자리에서 끊기며, 받던 LLM 답도 멈춘다.
- 계정은 그대로라 다시 로그인하면 들어온다. 다시 들어오지 못하게 하려면 **정지**를 쓴다(16.10절). 계정을 지우는 단추는 없다(27절).

### 16.7 위임 맡기기 — LLM 연결 관리(root) · 분류 관리 · 관리자가 건 중지 풀기 · 스페이스 관리 전체

**위임** 칸에는 줄의 역할에 따라 받을 수 있는 칸만 있다. 켜면 맡기고 끄면 거둔다. 그 사람의 다음 요청부터 먹는다 — 그 사람은 화면을 새로 고치면 된다.

| 칸 | 있는 줄 | 켜고 끄는 사람 | 맡겨 받은 사람이 하는 일 |
|---|---|---|---|
| **LLM 연결 관리** | admin | root | **LLM 연결** 메뉴에서 20절의 일 |
| **분류 관리** | member | admin·root | 남의 스페이스가 쓰는 분류도 이름을 바꾸고 지운다(17.1절) |
| **관리자가 건 중지 풀기** | member | admin·root | 관리자가 중지한 **자기** 스페이스를 다시 쓰기로 푼다(2.5절). 남의 스페이스는 풀지 못한다 |
| **스페이스 관리 전체** | member | admin·root | **스페이스 관리**에서 모든 스페이스를 찾아 중지·다시 쓰기·지우기(중지된 것), 휴지통에서 지운 스페이스 되살리기(17.1·17.2절). Crew가 아닌 스페이스의 **페이지는 읽지 못한다** |

- 켤 수 없는 칸은 눌리지 않고, 마우스를 올리면 까닭이 보인다 — LLM 연결 관리는 **시스템 관리자만 주고 거둔다**.
- admin 줄에 셋이 없는 것은 admin이 셋을 원래 하기 때문이다.
- 맡겨 받은 사람은 다른 사람에게 다시 맡기지 못한다.
- 역할이 바뀌면 그 역할이 받을 수 없는 칸은 사라진다 — admin이 member가 되면 LLM 연결 관리가, member가 admin이 되면 셋이 사라진다(admin으로서 원래 한다). 다시 돌아가도 돌아오지 않는다. 다시 켠다.
- 누가 언제 주고 거뒀는지는 감사로그 **user.grants.change**에 이전·이후와 함께 남는다.
- 칸을 누르면 그 줄의 칸들은 서버가 답할 때까지 눌리지 않는다. 화면을 연 사이 다른 관리자가 그 사람의 위임을 바꿨으면 **그 사이 누가 이 사람의 위임을 바꿨다 — 목록을 다시 본다**가 뜨고 목록을 다시 읽는다 — 지금 칸을 보고 다시 누른다. (화면이 본 목록을 함께 보내서, 옛 화면이 방금 거둔 위임을 모르고 되살리지 않는다.)
- 역할을 바꾸면 사라지는 위임이 있을 때, 그것을 거둘 수 없는 사람에게는 그 역할이 **역할** 칸에서 골라지지 않는다(서버도 **역할을 바꾸면 사라지는 위임을 거둘 권한이 없다: llm.manage**처럼 막는다) — LLM 연결 관리를 맡겨 받은 관리자를 member로 내리는 것은 root가 한다(16.3절).

### 16.8 누를 수 없는 줄

어떤 줄은 단추와 역할 칸이 눌리지 않고, 그 줄의 **조치** 칸 단추 아래에 **이 사용자를 관리할 권한이 없다 — 시스템 관리자에게 맡긴다**가 적혀 있다(단추에 마우스를 올려도 같은 말이 보인다).

- admin에게 root의 줄이 그렇다.
- LLM 연결 관리를 맡겨 받지 않은 admin에게, 맡겨 받은 admin의 줄이 그렇다. 그 사람의 비밀번호를 초기화해 대신 들어가면 맡긴 일까지 넘겨받게 되기 때문이다.
- 셋을 맡겨 받은 member의 줄은 admin이 관리한다 — admin은 셋을 원래 하므로 넘겨받아도 더 얻는 것이 없다.

표 아래에도 안내가 있다: **위임은 사람마다 주고 거둔다 — LLM 연결 관리는 시스템 관리자가 관리자에게, 분류 관리·관리자가 건 중지 풀기·스페이스 관리 전체는 관리자가 일반 사용자에게. 그 역할이 아니게 되면 사라진다. 자기에게 없는 위임을 가진 관리자는 시스템 관리자만 관리한다.**

### 16.9 사내 계정으로 들어오는 사람

- 가입 요청이나 승인 없이 처음 로그인할 때 계정이 생긴다(1.2절). 목록에서는 따로 표시되지 않는다.
- 역할과 이름·email은 로그인할 때마다 회사 로그인 시스템의 정보로 다시 정해진다.
- 비밀번호 초기화는 되지 않는다(16.5절). 로그인이 안 된다는 문의는 회사 로그인 시스템 쪽도 함께 본다(장애 대응 가이드 7.3절).
- **정지**는 사내 계정에도 먹는다. 회사 로그인이 되어도 이 위키가 거절하고, 정지 해제 전에는 로그인할 때마다 되살아나지 않는다(16.10절).

### 16.10 계정 정지 — 퇴사자를 막는다

그 사람 줄의 **정지**를 누르면 확인 대화 **이 사용자를 정지할까요?** 가 뜬다(0.4절): **홍길동(hong.gd)님을 정지한다. 세션과 편집 연결이 그 자리에서 끊긴다. 정지 해제로 되돌린다.** **멈춘다**를 누르면 화면 위에
**홍길동님을 정지했다.** 가 뜨고, 상태 칸이 **정지**가 된다. **그만두기**면 그대로다.

- 그 사람의 로그인이 모두 풀리고, 열어 둔 편집 화면이 그 자리에서 끊긴다. 다시 로그인하지 못한다 — 로그인 화면에는 다른 실패와 같은
  **아이디 또는 비밀번호가 올바르지 않다**가 뜬다. 사내 계정은 회사 로그인을 거쳐도 **이 계정은 정지돼 있다 — 관리자에게 문의한다**가 뜬다.
- 그 사람이 쓴 문서·댓글, 스페이스의 Crew 자리, 비밀번호는 **그대로 남는다.** 지우지 않는다 — 누가 무엇을 썼는지가 이어진다.
- 정지된 사람은 불러도(@아이디) 알림이 가지 않는다(11.1절).
- **정지** 단추는 상태가 **활성**·**잠김**인 줄에만 있다. 승인 대기 계정은 정지하지 않는다 — 승인하지 않고 두면 어차피 로그인하지 못한다.
- 자기 줄의 **정지**는 눌리지 않는다 — 단추 아래에 **자기 자신은 정지할 수 없다**가 적혀 있다(마우스를 올려도 보인다). 마지막 root는 정지할 수 없다: **마지막 root는 정지할 수 없다**.
  관리할 권한이 없는 사람의 줄(16.8절)도 눌리지 않는다.
- 되돌리려면 그 줄의 **정지 해제**를 누른다. 묻지 않고 곧바로 **활성**이 된다. 비밀번호·Crew 자리는 그대로라 그 사람이 다시 로그인하면 이어서 쓴다.
- 표 아래의 안내도 같은 말을 한다: **정지된 사람은 로그인하지 못한다. 쓴 문서·댓글·공간 소속은 남고, 정지를 풀면 그대로 이어진다.**
- 정지된 사람만 보려면 **상태**에서 **정지**를 고른다(16.1절). 누가 언제 정지하고 풀었는지는 감사로그 **user.suspend** · **user.unsuspend**에 남는다(18.2절).
- 계정을 지우는 단추는 없다(27절).

## 17. 스페이스·템플릿 관리

### 17.1 스페이스

- 관리자는 모든 스페이스를 열어 읽고 쓰며, 팀 스페이스의 Crew를 owner처럼 넣고 빼고 자리를 바꾼다 — 관리자가 중지한 스페이스에서도(그동안 owner는 못 한다, 2.3절).
- 첫 화면 목록에는 관리자에게도 자기 개인 스페이스와 자기가 Crew인 팀 스페이스만 나온다. **모든 스페이스**는 위 막대 **관리** → 왼쪽 칸 **스페이스 관리**에서 본다.

**스페이스 관리** 화면 — 제목 아래 **모든 스페이스를 찾아 중지·다시 쓰기·지우기를 하고 분류를 관리한다. 지운 스페이스는 휴지통에서 되살린다.** 그 아래 **모든 스페이스**와 **분류** 두 부분이다.

1. **모든 스페이스**의 거르기 줄 — **찾기**(안내 **이름·키**)에 이름이나 스페이스 기호(키)의 일부를 넣으면 입력을 멈춘 뒤 찾는다. **상태**에서 **전체**·**활성**·**중지**를 골라 거른다. 줄 오른쪽 끝에 **12개**처럼 수가 보인다.
2. 표의 열은 **이름**(누르면 그 스페이스) · **키** · **종류** · **상태** · **분류** · **Crew** · **만든 사람** · **조치**다. 개인 스페이스의 Crew 칸은 **—** 다. 중지된 줄의 상태에는 **주인이 걸었다** 또는 **관리자가 걸었다**가 붙는다 — 관리자가 건 중지는 **관리자가 건 중지 풀기**를 받은 owner만 푼다(2.5절). 맞는 것이 없으면 **맞는 스페이스가 없다.**
3. **조치** 칸의 **중지**는 확인 대화 **스페이스를 중지할까요?**(확정 **멈춘다**)로 묻는다. 중지된 줄에는 **다시 쓰기**(묻지 않는다)와 **지우기**(확인 대화 **스페이스를 지울까요?** — 확정 **지운다**)가 보인다. **주인이 걸었다** 줄에는 **관리자가 건 중지로 바꾸기**도 있다 — 확인 대화(확정 **넘겨받는다**)로 묻고, 누르면 **관리자가 걸었다**가 된다(2.5절). 관리자는 활성 스페이스를 곧바로 지우지 못한다 — 먼저 중지한다. 관리자가 주인이고 Crew가 본인뿐인 스페이스(자기 개인 스페이스 등)는 주인으로서 활성일 때도 지운다. 한 일은 거르기 줄 위의 알림띠에 **"기획팀 공간"을(를) 중지했다.** 처럼 뜬다.
4. 한 번에 500개까지 보인다. 500개가 차면 거르기 줄의 수가 **500개 — 한 번에 500개까지 보인다. 찾기로 좁힌다**가 된다.

**분류** — 같은 화면 아래의 **분류** 구획이다. 맨 위에 **분류를 지우면 쓰던 스페이스(휴지통 포함)는 분류 없음이 된다 — 어느 스페이스였는지 감사로그에 남는다.** 가 있고, 그 아래에 모든 분류가 한 줄씩 보인다. 줄마다 이름 칸을 고치고 **이름 바꾸기**, 또는 **지우기**. 목록 아래 **새 분류**에 이름을 넣고 **만들기**를 누르면 **분류 "운영"을(를) 만들었다.** 가 뜬다. 같은 이름이 이미 있으면 새로 생기지 않고 **분류 "운영"은(는) 이미 있다.**처럼 뜬다. 누구나 자기 스페이스의 관리 칸에서도 분류를 만든다(2.6절).

- 이름 칸 옆에 **공간 2개 (만든 사람의 것이 아닌 공간 1개)**처럼 그 분류를 쓰는 스페이스의 수가 보인다. 휴지통에 있는 스페이스도 센다(되살리면 그 분류를 쓴다). 수는 그 분류를 바꾸거나 지울 수 있는 사람과 만든 사람에게만 보인다 — 남의 개인 스페이스까지 센 수라서다.
- 이름 바꾸기·지우기는 **만든 사람과 관리자**가 한다. **만든 사람의 것이 아닌 스페이스가 쓰면** 관리자와 **분류 관리**를 맡겨 받은 사람만 한다. 할 수 없는 줄은 눌리지 않고, 마우스를 올리면 까닭이 보인다 — 내가 만든 분류면 **남의 공간이 쓰는 분류는 관리자나 '분류 관리'를 받은 사람이 바꾸고 지운다**, 아니면 **분류는 만든 사람과 관리자가 바꾸고 지운다**.
- **지우기**는 확인 대화 **분류를 지울까요?** 를 띄우고 **분류 "운영"을(를) 지운다. 이 분류를 쓰는 공간 2개(휴지통 포함)가 "분류 없음"이 된다. 되살릴 수 없다 — 어느 공간이었는지는 감사로그에 남는다.**처럼 묻는다(0.4절). **지운다**를 누르면 지운다. 지우면 **분류 "운영"을(를) 지웠다 — 쓰던 공간 2개는 분류 없음이 됐다.**가 뜬다. 되돌리려면 감사로그 **category.delete**의 상세(cleared)에서 그 스페이스들을 보고 분류를 다시 만들어 붙인다(18.2절).
- **분류 관리**만 맡겨 받은 member에게는 이 **분류** 구획만 보이고(제목 아래 안내는 **분류를 만들고 이름을 바꾸고 지운다.**), **모든 스페이스** 표는 **스페이스 관리 전체**를 받아야 보인다.

### 17.2 지운 스페이스 되살리기

**휴지통** 화면의 **지운 페이지** 아래에 있는 **지운 스페이스** 구획은 관리자와 **스페이스 관리 전체**를 맡겨 받은 사람에게만 보인다. 줄마다 이름, 그 옆에 스페이스 기호 · **만든 사람 홍길동** · 지운 시각이 있고 줄 끝에 **되살리기**가 있다(묻지 않는다). 되살리면 **"기획팀 공간"을 되살렸다. 안에 있던 문서도 함께 다시 보인다.** 가 뜬다. 없으면 **되살릴 스페이스가 없다.**

- 구획의 안내대로다: **스페이스를 되살리면 안에 있던 문서도 함께 다시 보인다. 따로 지운 문서만 위 목록에 남는다.**
- 보관 기간(기본 30일)이 지나 관리 담당이 정리하면 스페이스와 그 안의 페이지가 함께 영구히 없어진다. 되살릴 것이면 그 전에 한다(장애 대응 가이드 7.10-1절).

### 17.3 템플릿

템플릿은 새 페이지를 만들 때 고르는 문서 틀이다(3.1절). 관리자만 만들고 지운다. 모든 스페이스가 함께 쓴다.

1. 틀로 쓸 페이지를 연다. 보기 화면 맨 아래(**댓글** 다음)에 **템플릿** 구획이 있다. 평소에는 접혀 있다 — **이 문서를 템플릿으로 저장 · 만든 템플릿 3개** 줄을 누르면 펼쳐진다.
2. **이름**(필수. 칸 아래 도움말 **80자까지. 같은 이름이 있으면 새로 만들지 않는다.**)과 **설명**(도움말 **없어도 된다. 200자까지.**)을 쓰고 **템플릿으로 저장**을 누른다.
3. **"주간 회의록" 템플릿을 만들었다.** 가 뜬다.

- 지금 보이는 버전의 내용이 그대로 틀이 된다.
- 같은 이름이 이미 있으면 덮어쓰지 않고 **"주간 회의록"은 이미 있다. 내용을 바꾸려면 지우고 다시 만든다.** 가 뜬다.
- 펼친 구획의 **만든 템플릿** 목록에서 **지우기**를 누르면 확인 대화 **이 템플릿을 지울까요?** 가 뜬다(0.4절). **지운다**를 누르면 지운다 — 되살릴 수 없다. 펼친 구획 맨 아래의 안내대로 **템플릿을 지워도 그것으로 만든 문서는 그대로다 — 만들 때 내용을 복사하고 끝이다.**

## 18. 감사로그

### 18.1 보기와 거르기

**감사로그** 화면의 제목 아래에 **기록은 추가만 된다. 고치거나 지울 수 없다.** 가 있고, 그 아래에 접힌 **기록 단계:** 줄(18.3절), 거르기 줄, 기록 표가 차례로 있다. 이 화면은 폭 제한 없이 창 너비를 다 쓴다.

- 거르기 줄: **행위**(**전체** 또는 **로그인 실패 (auth.login.failure)** 처럼 한글 이름 뒤 괄호에 코드), **시작**과 **끝**(날짜. 끝 날짜의 하루도 들어간다), **요청 번호**(안내 **로그의 requestId**). 행위·시작·끝은 고르는 대로 곧바로 걸러진다. 요청 번호는 넣은 뒤 **거르기**를 누른다.
- 줄 오른쪽 끝에 **12건 (최대 200)** 처럼 수가 보인다. 최근 것부터 200건까지다. 많으면 기간이나 행위로 좁힌다. 하나도 없으면 표 아래에 **조건에 맞는 기록이 없다.** 와 **기간이나 행위를 넓혀 다시 거른다.**
- 표는 **시각** · **행위** · **주체**(한 사람) · **대상**(무엇에) · **상세** · **요청 번호**다.
  - **행위** 칸은 **로그인 실패 auth.login.failure** 처럼 한글 이름 뒤에 코드가 붙는다. 이 문서와 장애 대응 가이드는 코드로 적는다 — 코드로 찾으면 된다.
  - **대상** 칸은 두 줄이다. 첫 줄은 대상의 종류(**페이지** · **스페이스** · **사용자** · **아이디** 등)와, 기록이 그 대상의 이름을 싣고 있으면 그 이름(**페이지 · 회의록**)이다. 둘째 줄은 작은 글씨의 **전체 식별 번호**다 — 서버 기록(장애 대응 가이드)의 번호와 그대로 견준다. 페이지 제목처럼 사람이 지은 이름은 다른 것을 흉내 낼 수 있으니 종류와 번호를 함께 본다.
  - Crew 추가처럼 상세에 다른 사람의 아이디가 있어도 그것은 대상이 아니다 — 대상은 첫 줄의 종류(스페이스)다.
  - **상세** 칸은 **method: "oidc" · reason: "idp_rejected"** 처럼 "이름: 값"을 한 줄로 잇는다. 글인 값은 따옴표째 보인다 — 제목 같은 글이 " · "나 ": "를 품어 다른 항목처럼 읽히지 않게. 길면 잘려 있고, 누르면 펼쳐져 전체가 보인다.
- 요청 번호: 사용자가 "방금 오류가 났다"고 하면 관리 담당이 서버 기록에서 그 요청의 번호를 찾는다(장애 대응 가이드 7.28절). 그 번호를 **요청 번호** 칸에 붙여 넣고 **거르기**를 누르면 그 요청이 남긴 기록만 나온다. 모양이 틀리면 **요청 번호의 모양이 아니다 — 로그 줄의 requestId를 그대로 붙인다**가 뜬다.
- 보존 기간(기본 365일)이 지난 기록은 관리 담당이 지울 수 있다(운영 이관 가이드 4.2절).
- 검색한 것, 알림을 읽은 것, LLM 대화의 내용은 기록되지 않는다.

### 18.2 자주 찾는 행위

**행위** 고르기 칸에는 **한글 이름 (코드)** 로 보인다.

| 이럴 때 | 행위 |
|---|---|
| 로그인이 왜 실패했나(상세의 reason) | **로그인 실패 (auth.login.failure)** — 읽는 법은 장애 대응 가이드 7.1절 |
| 비밀번호 초기화 요청 | **비밀번호 초기화 요청 (auth.password.recover)** |

### 18.3 감사 기록 단계 (Phase 17)

**감사로그** 화면의 제목 바로 아래에 접힌 줄 **기록 단계: 3 · 전체 — 바꾸기** 가 지금 단계를 보인다(시스템 관리자가 아니면 끝이 **— 보기**). 그 줄을 누르면 펼쳐진다. 펼치면 먼저 **로그인·계정·권한·관리·설정, 만들기·고치기·지우기·옮기기·되살리기 같은 필수 기록은 단계와 무관하게 늘 남는다.** 가 보인다.

고르는 것은 **시스템 관리자(root)만**이다. 다른 관리자가 펼치면 **지금:** 뒤에 지금 단계의 뜻과 **단계는 시스템 관리자만 바꾼다.** 가 보인다. 시스템 관리자에게는 **단계 고르기** 아래에 셋이 있다.

| 고르는 칸 | 남기지 않는 것 |
|---|---|
| **3 · 전체 — 모든 행위를 남긴다 (기본)** | 없다 — 모든 행위를 남긴다 |
| **2 · 줄임 — 실시간 편집의 자동 저장을 남기지 않는다** | 실시간 편집의 자동 저장(`page.collab.save`) — 사람이 누른 **저장하고 보기로**와 제목 바꾸기는 늘 남는다 |
| **1 · 최소 — 필수 기록만 — 자동 저장·첨부 받기·HTML 내보내기·메일 발송 성공·LLM 질문을 남기지 않는다** | 위에 더해 첨부 받기(`attachment.download`)·HTML 내보내기(`page.export`)·메일 발송 성공(`mail.send`)·LLM 질문(`llm.ask`) |

- 2와 1의 칸 아래에는 **남기지 않는 것: 실시간 편집 자동 저장** 처럼 빠지는 행위가 한글 이름으로 적혀 있다.
- 로그인·계정·권한·관리·설정, 만들기·고치기·지우기·옮기기·되살리기, 실시간 편집에서 거절된 변경, 메일 실패 같은 **필수 기록은 단계와 무관하게 늘 남는다.**
- 단계를 고르고 **단계 저장**을 누르면(지금 단계와 같으면 눌리지 않는다) 접힌 줄 위에 **저장했다 — 다음 기록부터 먹는다. 바꾼 것은 감사로그에 settings.update로 남는다.** 가 뜬다. 이미 남은 기록은 지워지지 않는다.
- 사내 보안 규정이 첨부 받기·내보내기 기록을 요구하면 **2 · 줄임**보다 낮추지 않는다.

## 19. 운영 설정

감사 기록 단계는 이 화면에 없다 — 제목 아래 안내대로 **감사 기록 단계는 감사로그 화면에서 시스템 관리자가 고른다.** (18.3절)

**운영 설정** 화면에서 정책값을 바꾼다. 값들은 네 묶음(**세션·계정** · **업로드·첨부** · **보존 기간** · **LLM 대화**)으로 나뉘고, 한 줄에 값 하나다 — 왼쪽에 이름, 오른쪽에 숫자 칸과 단위, 칸 아래에 도움말. 맨 아래의 **저장**을 누르면 폼 위에 **저장했다. 다음 요청부터 바로 먹는다 — 다시 띄울 필요가 없다.** 가 뜬다. 서버를 다시 켤 필요 없이 곧바로 먹는다.

이름은 **세션 유휴 시간 (sessionIdleMinutes)** 처럼 한글 이름 뒤 괄호에 코드가 붙는다. 코드는 감사로그 **settings.update**의 상세와 장애 대응 가이드가 쓰는 이름이다.

| 묶음 | 화면의 이름 | 뜻(칸 아래 도움말) | 단위 | 기본값 |
|---|---|---|---|---|
| 세션·계정 | **세션 유휴 시간 (sessionIdleMinutes)** | **이만큼 아무것도 하지 않으면 로그아웃된다.** | 분 | 30 |
| 세션·계정 | **세션 최대 시간 (sessionAbsoluteHours)** | **로그인한 뒤 이만큼 지나면 쓰고 있어도 다시 로그인한다.** | 시간 | 12 |
| 세션·계정 | **비밀번호 최소 길이 (passwordMinLength)** | **8자 아래로는 내리지 못한다.** | 자 | 8 |
| 세션·계정 | **비밀번호 문자 종류 (passwordMinCharClasses)** | **영문 대문자·소문자·숫자·특수문자 가운데 몇 종을 섞는가. 2종 아래로는 내리지 못한다.** | 종 | 2 |
| 세션·계정 | **잠금까지 실패 횟수 (lockoutThreshold)** | **비밀번호를 이만큼 잇달아 틀리면 계정을 잠근다.** | 회 | 5 |
| 세션·계정 | **잠금 시간 (lockoutMinutes)** | 잠그는 시간(도움말 없음) | 분 | 15 |
| 업로드·첨부 | **업로드 최대 크기 (uploadMaxMb)** | 첨부 파일 하나의 최대 크기. 칸 아래에 **이 서버의 천장 20MB — 그 위로는 올리지 못한다.** 가 보이고, 그 천장보다 크게는 못 한다 | MB | 20 |
| 보존 기간 | **휴지통 보존 기간 (trashRetentionDays)** | **지난 것은 달마다 하는 정리 작업이 되살릴 수 없게 지운다.** | 일 | 30 |
| 보존 기간 | **감사로그 보존 기간 (auditRetentionDays)** | **90일 아래로는 내리지 못한다 — 감사 추적을 설정 하나로 지우지 못하게.** | 일 | 365 |
| LLM 대화 | **LLM 대화 보존 기간 (llmRetentionDays)** | **고정하지 않은 대화는 마지막으로 쓴 뒤 이만큼 지나면 지워진다.** | 일 | 7 |
| LLM 대화 | **사람마다 대화 수 (llmConversationMax)** | **고정한 것도 센다. 넘으면 고정하지 않은 것 가운데 오래된 것부터 지워진다.** | 개 | 100 |
| LLM 대화 | **사람마다 고정 수 (llmPinnedMax)** | **대화 수보다 작아야 한다. 0이면 고정을 쓰지 않는다.** | 개 | 20 |

**업로드·첨부** 묶음에는 **허용 확장자** 줄도 있다(아래).

- 범위를 벗어난 값은 저장하지 않고, 폼 위의 오류 알림띠에 **sessionIdleMinutes는 1~1440 사이의 정수여야 한다** 처럼 코드와 허용 범위를 알려 준다. 고정 수가 대화 수보다 작지 않으면 **고정 수(llmPinnedMax 20)는 대화 수(llmConversationMax 20)보다 작아야 한다** 로 시작하는 말로 막는다.
- 첨부 크기를 천장보다 크게 하려면 서버 설정을 바꿔야 한다. 서버 쪽 일이다(장애 대응 가이드 7.13절, 운영 이관 가이드 5절).
- 비밀번호 규칙(**비밀번호 최소 길이** · **비밀번호 문자 종류**)을 바꾸면 가입·비밀번호 변경 화면의 안내문도 그 규칙으로 바뀐다. 기본 규칙의 안내는 **8자 이상, 영문 대·소문자·숫자·특수문자 중 2종 이상, 공백 없이**다. 이미 쓰는 비밀번호는 그 사람이 바꿀 때까지 그대로 쓰인다.
- 로그인 유지 시간을 바꾸면 이미 로그인한 사람에게도 다음 요청부터 먹는다.
- **허용 확장자** 줄에서 확장자마다 붙은 칸으로 받을 파일 종류를 켜고 끈다. 줄 아래 도움말대로 **판정 규칙이 있는 것만 켤 수 있다. 목록 밖 확장자는 내용 검사를 지나치게 된다.** 적어도 하나는 켜 두어야 한다.
- 누가 언제 무엇을 바꿨는지는 감사로그 **settings.update**에 이전·이후 값이 남는다. 되돌리려면 이전 값을 다시 넣고 저장한다.

## 20. LLM 연결 관리

root와, root가 맡긴 admin(16.7절)에게 왼쪽 칸 **관리** 묶음에 보이는 **LLM 연결** 화면이다. 제목 아래 안내: **사내 LLM 서버(OpenAI 호환 — vLLM)를 등록하면 모든 사용자가 "LLM 질문" 메뉴에서 쓴다. 지우면 곧바로 못 쓴다. 등록·삭제는 감사로그에 남는다.**

**등록된 연결 2개**처럼 수가 붙은 목록 표가 먼저 있고, 그 아래에 **등록** 구획이 있다. 목록 표는 **이름** · **모델** · **주소** · **API 키** · **등록한 사람** · **조치**(**연결 확인** · **삭제**)다. API 키는 **있음**이나 **없음**으로만 보인다. 주소가 http로 시작하면 옆에 **(암호화 안 됨)** 이 붙는다. 하나도 없으면 **등록된 LLM이 없다.**

등록:

1. 주소·모델 이름·API 키를 LLM 서버 담당에게 받는다.
2. **등록** 구획에 **이름**(필수. 사용자에게 보이는 이름), **주소**(필수. 칸 아래 도움말 **OpenAI 호환 API의 /v1까지**, 칸 안 예시 http://llm.example.internal:8000/v1), **모델**(필수. 칸 안 예시 Qwen/Qwen3-32B), **API 키**(도움말 **없으면 비운다. 저장하면 다시 볼 수 없다**)를 채운다. 주소의 모양이 틀리면 **주소** 칸 아래에 까닭이 뜨고 등록되지 않는다.
3. 구획 맨 아래의 **등록**을 누르면 **"사내 Qwen"을(를) 등록했다 — 연결을 확인한다**처럼 뜨고 곧바로 연결을 확인한다. 등록 칸들은 곧바로 비워진다 — 넣은 API 키도 화면에 남지 않는다.
4. 목록 표에서 그 연결의 줄 바로 아래 줄에 **연결됨**과 **모델 3개:** 뒤에 모델 이름들이 보이면 끝이다.

- 주소가 http로 시작하면 **등록** 단추 위에 **http 주소다**로 시작하는 주의 알림띠가 뜬다. 질문과 답(키를 넣었으면 키도)이 암호화되지 않고 사내망을 지난다는 뜻이다. LLM 서버가 https를 받으면 https 주소로 등록한다.
- 줄의 **연결 확인**을 누르면 다시 확인한다. 그 줄 바로 아래 줄에 **연결 확인 중…** 다음에 **연결됨**이나 **연결 안 됨** — 뒤에 까닭이 뜬다. 연결됐는데 **등록한 모델이 목록에 없다. 모델 이름을 확인한다**가 붙으면 모델 이름이 틀렸다. 까닭별 조치는 장애 대응 가이드 7.24절이다.
- 줄의 **삭제**를 누르면 확인 대화 **이 연결을 지울까요?** 가 뜬다(0.4절) — **"사내 Qwen"을(를) 지운다. 이 LLM으로 한 대화는 남고, 사람들은 다른 LLM으로 이어 묻는다.** **지운다**를 누르면 **"사내 Qwen"을(를) 지웠다** 가 뜨고, 곧바로 아무도 못 쓴다.
- API 키가 바뀌었거나 주소를 고쳐야 하면 지우고 다시 등록한다. 고치는 칸은 없다. 대화는 남는다.
- 같은 이름은 쓸 수 없다: **같은 이름의 LLM이 이미 있다**
- 처음 붙이는 날 필요한 서버 쪽 준비(사내 인증서 등)는 [반입 가이드](운영가이드_반입.md) 10절에 있다.

| **그 사이 누가 상태를 바꿨다 — 다시 본다** | 두 사람이 같은 스페이스를 거의 동시에 중지하거나 풀었다(누가 건 중지인지가 바뀐 것도) | 화면이 지금 상태를 다시 읽는다 — 다시 보고 누른다 |

| **부모 페이지를 찾을 수 없다** | 고른 부모가 그 사이 지워졌다 | 새로고침하고 다시 고른다(3.3절) |

### 23.1 화면의 틀 — 왼쪽 칸·넓게 보기·확인 대화

| 화면에 뜬 말, 겪은 일 | 뜻 | 할 일 |
|---|---|---|
| 왼쪽 칸이 통째로 사라졌다, 본문이 화면 왼쪽 끝부터 시작한다 | 왼쪽 칸이 접혔다. 위 막대의 단추나 Ctrl+[ 를 눌렀거나, 창이 1280px보다 좁아 처음부터 접혀 있다 | 위 막대 맨 왼쪽의 세 줄 모양 단추를 누르거나, 글을 쓰는 칸 바깥을 누른 뒤 Ctrl+[ 를 누른다. 한 번 펴면 이 브라우저가 기억한다(0.3절) |
| 왼쪽 칸에 페이지 트리가 아니라 **바로가기**가 보인다 | 지금 화면이 스페이스 밖(첫 화면·검색·라벨·휴지통·알림함 등)이다 | 스페이스나 페이지를 열면 그 스페이스의 트리로 바뀐다(0.3절) |
| 스페이스 안에서 왼쪽 칸의 **관리** 묶음이 안 보인다 | 스페이스 안의 왼쪽 칸은 그 스페이스의 메뉴와 트리다 | 위 막대의 **관리**를 누른다(15절) |
| 넓게 보기가 풀렸다, 글 칸이 다시 좁다 | 넓게 보기는 브라우저마다 기억한다. 다른 PC나 다른 브라우저에서는 처음처럼 좁다 | 도구 줄(편집 화면은 편집 줄)의 **넓게 보기**를 한 번 누른다. 그 브라우저에서는 다시 기억한다(3.2절) |
| 왼쪽 칸이 창을 좁혀도 저절로 접히지 않는다 | 창의 폭은 화면을 처음 열 때 한 번만 본다(창 크기를 바꿔도 따라가지 않는다). 한 번이라도 직접 접거나 편 브라우저는 폭과 상관없이 그 선택을 따른다 | 단추나 Ctrl+[ 로 접는다(0.3절) |
| 지우기를 눌렀는데 화면 가운데에 상자가 떴다 | 잘못 누르면 되돌리기 어려운 일이라 한 번 묻는다(목록은 0.4절) | **지운다**(또는 **뺀다** · **멈춘다** 등)를 눌러야 한다. 그만두려면 **그만두기**나 Esc(0.4절) |
| 페이지를 삭제했는데 묻지 않았다 | 페이지는 휴지통에서 되살리므로 묻지 않는다 | 되살리려면 **휴지통**(13절) |

## 24. 편집·저장

| 화면에 뜬 말, 겪은 일 | 뜻 | 할 일 |
|---|---|---|
| **연결이 끊겼다. 지금 쓰는 내용은 저장되지 않는다 — 다른 곳에 복사한 뒤 새로고침한다** | 서버와의 편집 연결이 끊겼다(5.4절) | 쓰던 내용을 복사하고 새로고침한다. 되풀이되면 관리자에게(7.19·7.19-1절) |
| 편집 줄에 **연결 끊김**이나 **자동 저장 멈춤**이 붙었다 | 편집 줄 아래에 까닭을 말하는 알림이 떠 있다 | 맨 위로 올라가 그 알림을 읽는다(5.4절) |
| **서버가 이 편집을 받지 않았다**로 시작하는 알림 | 서버가 방금 보낸 편집을 받지 않고 내 연결만 끊었다 | 복사하고 새로고침한다. 계속되면 무엇을 하다 끊겼는지 관리자에게(7.23절) |
| **자동 저장이 멈췄다:** 로 시작하는 알림 | 글은 보이지만 버전이 남지 않는다 | 까닭대로 고친다(5.4절). 모르겠으면 복사해 두고 관리자에게(7.20절) |
| **저장하고 보기로**를 눌렀는데 버전이 늘지 않았다 | 고친 것이 없거나 자동 저장이 이미 남겼다 — 그래서 그대로 보기로 왔다 | 할 것 없다. 내용은 남아 있다(5.2절) |
| 그 밖의 **저장되지 않았다:** | 5.2절 표 | 5.2절 표 |
| 버전이 늘지 않는다 | 아직 치는 중이거나, 내용이 그대로이거나, 모두 지운 빈 페이지다 | 손을 멈추고 몇 초 기다린다. 정말 비우려면 **저장하고 보기로**(7.20절) |
| 바꾼 제목이 남지 않았다 | 같이 보던 사람이 **그 뒤에 제목을 다시 고쳤다**(나중에 고친 쪽이 남는다), 또는 연결이 끊긴 채 바꿨다 | 다시 바꾸고 몇 초 기다리거나 **저장하고 보기로**를 누른다(5.1절) |
| 동료가 바꾼 제목이 내 화면에 안 보인다 | 제목은 같이 보는 사람의 화면에 곧바로 바뀌어 보이지 않는다 | 새로고침한다(5.1절) |
| **다른 사람이 먼저 저장했다** | 실시간 편집이 꺼진 서버에서 누가 먼저 저장했다 | 5.5절(7.6절) |
| 같이 쓰던 사람들의 화면이 한꺼번에 끊겼다 | 누가 옛 버전으로 되돌렸을 수 있다 | 끊긴 화면에서 쓰던 것을 복사하고 새로고침한다(6.3절) |
| 친 이메일 주소가 링크가 되지 않는다 | 일부러 그렇게 했다 | 4.2절 |
| 표를 넣는 단추가 없다, 그림이 들어가지 않는다 | 편집기에 그 단추와 그림 칸이 없다 | 표는 붙여 넣고(4.3절), 그림은 첨부한다(4.4절) |
| 동료의 화면에 내 이름과 커서가 안 보인다 | 드물게 생긴다. 편집은 그대로 오간다 | 아무 글자나 하나 친다(7.23절 끝) |

## 25. 첨부·검색·알림

| 화면에 뜬 말, 겪은 일 | 뜻 | 할 일 |

| **허용하지 않는 확장자다: exe**처럼 | 받지 않는 종류다 | 받는 종류는 8절이다. 켤 수 있는 종류인지 관리자에게 묻는다(7.9절) |
| **확장자(.pdf)와 형식(text/html)이 맞지 않는다**처럼 | 파일 이름과 브라우저가 알린 종류가 다르다 | 그 형식으로 제대로 저장해 다시 올린다(7.9절) |
| **내용이 .pdf 형식이 아니다**처럼 | 이름만 바꾼 파일이다 | 그 형식으로 제대로 저장해 다시 올린다(7.9절) |
| **파일이 너무 크다 (상한 20MB)** | 크기 상한을 넘었다 | 줄이거나 나눠 올린다. 상한은 관리자가 정한다(19절) |
| **HTTP 413**만 뜬다 | 서버 앞단이 큰 파일을 막았다 | 관리자에게 알린다(7.9절) |
| **빈 파일은 올릴 수 없다** | 내용이 없는 파일이다 | 내용이 든 파일을 올린다 |
| 찾는 페이지가 검색에 안 나온다 | 볼 수 없는 스페이스, 휴지통, 댓글·첨부 안의 글, 또는 20건 밖이다 | 7절. 그래도 안 나오면 관리자에게(7.10절) |
| 불렀는데 알림이 가지 않았다 | 그 사람이 그 스페이스를 볼 수 없거나, 아이디가 틀렸거나, 승인 전 계정이거나, 정지된 계정이거나, @ 앞에 글자가 붙었다 | 11.1절(7.12절) |
| 이름 대신 **문서에서 불렸다** | 누가 불렀는지 확실하지 않다 | 고장이 아니다(7.22절) |
| 제목 대신 **(지워진 글)** | 그 글이 지워졌거나 지금 볼 수 없다 | 알림만 남은 것이다 |
| 불렸다는 메일이 오지 않는다 | 서버에서 메일을 켜지 않았거나 메일 쪽 문제다 | 알림함을 본다. 관리자에게 알린다(7.21절) |
| **복사하지 못했다 — 브라우저가 클립보드를 막았다** | 브라우저가 복사를 막았다 | 본문을 직접 골라 Ctrl+C로 복사한다 |

## 26. 사내 LLM

| 화면에 뜬 말, 겪은 일 | 뜻 | 할 일 |
|---|---|---|
| **등록된 LLM이 없다 — 시스템 관리자에게 등록을 요청한다.** | 쓸 수 있는 LLM이 없다 | 관리자에게 등록을 부탁한다(20절) |
| **이미 답을 받고 있다 — 끝나거나 중지한 뒤에 묻는다** | 다른 탭이나 창에서 답을 받는 중이다 | 그 탭에서 **중지**하거나 끝나기를 기다린다 |
| **답변이 늦어지고 있습니다.** | 사내 LLM 서버가 붐빈다 | 기다린다(7.25-1절) |
| **세션이 끝나 답을 멈췄다 — 다시 로그인한다** | 답을 받는 사이 로그인이 끝났다 | 다시 로그인해 묻는다 |
| **대화가 모델이 한 번에 읽을 수 있는 길이를 넘었다 — 새 대화를 시작한다**로 시작하는 말 | 대화가 너무 길다 | **새 대화**에서 앞 대화의 요점을 붙여 묻는다(14.4절) |
| **대화 하나에 메시지는 200개까지다 — 새 대화를 시작한다** | 대화 하나의 상한이다 | **새 대화**를 연다 |
| **답이 모델의 길이 상한에서 잘렸다 — 대화가 길면 새 대화를 시작한다** | 모델이 쓸 수 있는 만큼 쓰고 멈췄다 | 이어서 써 달라고 묻거나 새 대화를 연다 |
| **시간 상한(10분)을 넘었다** (괄호 안은 설정에 따라 다르다) | 답 하나가 시간 상한을 넘었다. 거기까지는 저장된다 | 질문을 나눠 묻는다. 자주 나면 관리자에게(7.25절) |
| **연결이 끊겼다 — 답이 저장됐는지 목록을 다시 본다** | 브라우저와 위키 서버 사이가 끊겼다 | 왼쪽 칸의 대화 목록을 다시 본다 |
| **LLM 서버에 닿지 않는다**로 시작하는 말 | 위키 서버가 LLM 서버에 닿지 못했다 | 관리자에게 알린다(7.24절) |
| **대화를 찾을 수 없다 — 지웠거나 보존 기간이 지났다** | 그 대화가 없어졌다 | 되살릴 수 없다(7.27절) |
| 대화가 목록에서 사라졌다 | 기간이 지났거나 대화 수를 넘었다 | 14.6절. 오래 둘 대화는 **고정**한다(7.27절) |
| 답이 흘러나오지 않고 끝에 한꺼번에 나온다 | 중간의 장비가 답을 모았다가 보낸다 | 관리자에게 알린다(7.25절) |

## 27. 화면에 아직 없는 것

찾아도 없는 기능이다. 필요하면 관리자나 개발 담당에게 원하는 말을 그대로 전한다. [기능백로그](기능백로그.md)에 적힌다.

| 없는 것 | 지금은 |

| 편집기의 모양 단추 모음 | 줄 맨 앞 기호와 단축키(4.1절) |
| 표를 새로 넣기, 칸 합치기·열 더하기 | 다른 곳의 표를 붙여 넣는다(4.3절) |

| 댓글 고치기 | 지우고 다시 쓴다(9절) |
| 위 막대에서 바로 찾기(찾는 칸) | 위 막대의 **검색**으로 검색 화면을 열어 찾는다(7절) |
| 트리에서 끌어 옮기기, 다른 스페이스로 옮기기 | 페이지 보기의 **옮기기**로 같은 스페이스 안에서 옮긴다(3.3절) |

| 내 이름·email 바꾸기 | 관리 담당에게 묻는다 |
