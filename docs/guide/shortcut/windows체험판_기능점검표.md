# workfluence Windows 체험판 기능 점검표

- 읽는 사람: Windows PC에서 workfluence(사내 위키) 체험판을 띄워 기능을 하나씩 확인해 보려는 사람. 개발을 몰라도 위에서부터 차례로 하면 된다
- 이 파일 하나로 끝난다 — 받기, 띄우기, 기능 확인, 결과 적기, 끄기까지 모두 여기 있다
- 걸리는 시간: 준비 10분 + 점검 1~2시간 (필수만 하면 40분쯤)
- 작성일: 2026-10-01 / 작성 LLM: Claude Opus 5.5

> **체험판이다 — 운영 설치가 아니다.** 암호화 연결 없이 이 PC 안에서만 쓴다. **실제 업무 문서·직원 정보를 넣지 않는다.** 이름·email·문서는 모두 지어낸 것으로 쓴다(이 표의 예시 그대로 써도 된다).

## 준비 1. 체험판 받기

- [ ] 1. 브라우저로 GitHub에 **로그인**한다 (저장소는 공개지만 받으려면 로그인해야 한다)
- [ ] 2. 주소창에 이 주소를 연다: https://github.com/hipiboy7/workfluence/actions/workflows/windows-local.yml
- [ ] 3. 목록에서 **맨 위의 초록 체크(✓) 줄**을 누른다
  - 빨간 X 줄은 시험을 통과하지 못한 판이라 쓰지 않는다. 회색 줄은 건너뛴다. 노란 동그라미는 만드는 중이다 — 5분쯤 뒤 다시 본다
- [ ] 4. 열린 화면 위쪽 요약의 **커밋 번호**(7자리, 예: b4caca0)를 위 **점검 정보** 표에 적는다
- [ ] 5. 화면 맨 아래 **Artifacts**에서 **workfluence-windows-trial**을 눌러 받는다 (zip, 약 80MB)
  - 같은 곳의 다른 두 항목(lgpl-sources, logs)은 받지 않아도 된다
  - Artifacts가 비어 있으면 만든 지 30일이 지난 것이다 — 개발 담당에게 새로 만들어 달라고 한다

## 준비 2. 풀기

- [ ] 1. 받은 zip을 **오른쪽 클릭 → 속성** → 아래쪽 **차단 해제**에 체크 → **확인**
- [ ] 2. zip을 **오른쪽 클릭 → 압축 풀기** → 대상 폴더를 **짧은 영문 경로**로 적는다
  - 권하는 자리: C:\Users\(영문 사용자 이름)\wf
  - 사용자 이름에 한글이 있으면: C:\wf (경로에 한글이 있으면 데이터베이스가 뜨지 않는다)
  - **다운로드 폴더 안에 그대로 풀지 않는다** — 경로가 길면 파일이 빠진 채 풀린다
- [ ] 3. 푼 폴더에 **시작.cmd · 멈추기.cmd · 읽어보기.txt** 파일과 **node · pgsql · app** 폴더가 보인다

> 예전에 체험판을 쓰던 PC라면 먼저 예전 폴더의 **멈추기.cmd**를 누른다. 둘이 같은 자리를 써서 켜 둔 채면 새 판이 뜨지 않는다.

## 준비 3. 띄우고 첫 로그인

- [ ] ★ 1. **시작.cmd**를 두 번 누른다. 까만 창이 열린다. 처음에는 1~2분 걸린다
  - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**
- [ ] ★ 2. 까만 창에 **위키가 떴다**가 나오고 브라우저가 http://127.0.0.1:3000 을 연다 (안 열리면 주소창에 직접 적는다)
- [ ] 3. Windows 방화벽이 "Node.js" 액세스를 허용할지 물으면 **취소**를 누른다 (이 PC 안의 브라우저는 그래도 된다)
- [ ] ★ 4. 아이디 **root**, 비밀번호는 **까만 창에 보이는 첫 비밀번호**로 로그인한다
  - 첫 비밀번호를 놓쳤으면 푼 폴더의 **data\settings.env**를 메모장으로 열어 WF_ROOT_PASSWORD= 줄을 본다
- [ ] ★ 5. 곧바로 **비밀번호 변경** 화면이 나온다. 새 비밀번호(8자 이상, 영문 대문자·소문자·숫자·특수문자 중 2종 이상)를 정하면 첫 화면(**스페이스**)이 열린다
- [ ] 6. **까만 창은 점검이 끝날 때까지 닫지 않는다** — 그 창이 위키를 띄우고 있다

> 이 표에서 "root"는 시스템 관리자다. 점검하며 쓸 계정 둘을 아래 1절에서 만든다.
>
> | 아이디 | 이름 | email | 쓰임 |
> |---|---|---|---|
> | tester1 | 시험일 | tester1@example.internal | 쓰기 권한(editor)으로 같이 고치는 사람 |
> | tester2 | 시험이 | tester2@example.internal | 읽기만(viewer) 하는 사람 |
>
> 두 사람을 동시에 띄우려면 브라우저의 **InPrivate 창(Edge, Ctrl+Shift+N)** 이나 다른 브라우저를 하나 더 쓴다.

## 1. 로그인·계정

- [ ] ★ 1.1 화면 틀 — 로그인 뒤 맨 위 막대에 **스페이스 · 검색 · LLM 질문 · 휴지통 · 관리 · 알림 · 내 이름 · 비밀번호 변경 · 로그아웃**이 보이고, 왼쪽 칸이 있다. 맨 왼쪽 세 줄 단추(또는 Ctrl+[)로 왼쪽 칸이 접히고 펴진다
- [ ] ★ 1.2 가입 요청 — 로그아웃 → 로그인 화면의 **가입 요청** → tester1의 아이디·이름·email·비밀번호를 넣고 **가입 요청** → **가입 요청이 접수됐다…**가 뜬다
- [ ] 1.3 승인 전 로그인 — 승인 전에 tester1로 로그인하면 **아이디 또는 비밀번호가 올바르지 않다**가 뜬다
- [ ] ★ 1.4 가입 승인 — root로 로그인 → **관리 → 사용자 관리** → 상태가 **승인 대기**인 tester1 줄의 **승인** → 상태가 **활성**이 된다
- [ ] ★ 1.5 승인 뒤 로그인 — tester1로 로그인된다. 첫 화면 **내 스페이스**에 **시험일의 공간**(개인)이 저절로 생겨 있다
- [ ] 1.6 같은 방법으로 tester2도 가입 요청 → root가 승인한다
- [ ] 1.7 비밀번호 바꾸기 — 위 막대 **비밀번호 변경**에서 새 비밀번호를 현재와 **같게** 넣으면 **새 비밀번호가 현재 비밀번호와 같다…**, 확인 칸을 다르게 넣으면 **새 비밀번호와 확인이 다르다**가 뜨고 **변경**이 눌리지 않는다. 맞게 넣으면 바뀐다
- [ ] 1.8 비밀번호 규칙 — 가입 요청에서 비밀번호를 짧게(예: abc) 넣으면 화면이 까닭을 말하고 받지 않는다
- [ ] 1.9 잠금 — tester2로 비밀번호를 **5번** 틀리게 넣는다 → 그 뒤에는 맞는 비밀번호도 들어가지 않는다 → root의 **사용자 관리**에 tester2가 **잠김**으로 보이고, **잠금 해제**를 누르면 다시 로그인된다
- [ ] 1.10 아이디 찾기 — 로그인 화면 **아이디·비밀번호 찾기** → 왼쪽 **아이디 찾기**에 tester1의 email과 이름을 넣고 **찾기** → **아이디:** 뒤에 앞 몇 글자만 보이고 **(일부만 표시된다)**가 붙는다. 틀린 값이면 **일치하는 정보로 찾을 수 없다. 관리자에게 문의한다.**
- [ ] 1.11 비밀번호 찾기 화면 — 비밀번호 찾기 칸이 **이름 + email**을 받고, **관리자에게 초기화 요청** 단추와 **이메일이 기억이 안나시나요?**가 있다
  - **"내 email로 재설정 링크 받기" 단추는 체험판에서 보이지 않는 것이 정상이다** (메일이 연결되지 않아서다)
- [ ] 1.12 초기화 요청 → 관리자 알림 — tester1의 이름·email로 **관리자에게 초기화 요청** → root로 들어가 위 막대 **알림**에 **시험일 (tester1)님의 이름·email로 비밀번호 초기화가 요청됐다…**가 와 있다
- [ ] 1.13 email 확인 요청 → 시스템 관리자 알림 — 로그아웃 → **이메일이 기억이 안나시나요?**에 tester1의 **아이디·이름**을 넣어 보낸다 → root의 **알림**에 email 확인 요청이 오고, **사용자 관리에서 보기**를 누르면 사용자 목록에서 이름 아래에 email이 작게 보인다
- [ ] 1.14 틀린 값도 같은 답 — 1.12·1.13에 지어낸 이름·email(없는 사람)을 넣어도 화면의 답이 맞을 때와 **똑같다** (있는 계정인지 드러내지 않는다). root의 알림에는 오지 않는다
- [ ] 1.15 로그아웃 — **로그아웃**을 누르면 로그인 화면으로 가고, 브라우저 뒤로 가기로 돌아가도 내용이 보이지 않는다

## 2. 스페이스

- [ ] ★ 2.1 팀 스페이스 만들기 — root로 첫 화면 **팀 스페이스 만들기**의 이름 칸에 **시험팀 공간**을 넣고 **만들기** → **내 스페이스** 표에 **팀**으로 생긴다
- [ ] ★ 2.2 Crew 넣기 — 시험팀 공간을 열고 **Crew** 칸의 **아이디로 Crew 추가**에 tester1을 **editor (쓰기)**로, tester2를 **viewer (읽기만)**으로 넣는다
- [ ] 2.3 자리 바꾸기 — Crew 표에서 tester2 줄의 역할 고르기를 editor로 바꿨다가 다시 viewer로 되돌린다 — 고르는 즉시 바뀐다
- [ ] 2.4 Crew 빼기 — tester2 줄의 **제거** → 확인 대화 **Crew에서 뺄까요?** → **뺀다**. tester2로 들어가면 첫 화면에 시험팀 공간이 없다(Crew가 아닌 팀 공간은 보이지도 않는다). 확인 뒤 다시 viewer로 넣는다
- [ ] 2.5 스페이스 정보 바꾸기 — 스페이스 첫 화면 아래 **스페이스 정보**에서 설명을 넣고, **새 분류** 칸에 **시험분류**를 넣어 **분류 만들기** → **저장** → **저장했다.**가 뜨고 제목 아래에 분류가 보인다
- [ ] 2.6 스페이스 중지 — **위험 구역**의 **중지** → **스페이스를 중지할까요?** → **멈춘다** → 제목 아래 **중지됨 — 읽기만 된다**. tester1로 들어가 보면 **새 페이지**·**편집**이 없다
- [ ] 2.7 다시 쓰기 — **위험 구역**의 **다시 쓰기** → 다시 쓸 수 있다
- [ ] 2.8 viewer 권한 (3절에서 페이지를 만든 뒤에 한다) — tester2로 시험팀 공간을 열면 페이지는 읽히지만 **새 페이지·편집·삭제·첨부 올리기·라벨 붙이기·댓글 쓰기**가 없다

## 3. 페이지·페이지 트리

- [ ] ★ 3.1 새 페이지 — root로 시험팀 공간 첫 화면의 **새 페이지** 구획에 제목 **회의록**, 위치 **맨 위**로 **만들기** → 곧바로 편집 화면이 열린다
- [ ] ★ 3.2 하위 페이지 — 회의록 보기 화면의 **하위 페이지 만들기** → 위치에 회의록이 골라져 있다 → 제목 **10월 회의**로 만든다. 왼쪽 칸 트리에서 10월 회의가 회의록 **밑에 들여 써서** 보인다
- [ ] 3.3 트리 접기 — 트리의 회의록 줄 앞 화살표를 누르면 아래가 접히고 다시 누르면 펴진다. 지금 보는 페이지는 파란 바탕에 굵게 보인다
- [ ] 3.4 빵부스러기 — 10월 회의 보기 화면 맨 위 줄에 **시험팀 공간 / 회의록 / 10월 회의**가 보이고, 앞의 이름을 누르면 그리로 간다
- [ ] 3.5 옮기기 — 맨 위에 페이지 **참고자료**를 하나 더 만든다 → 10월 회의의 **옮기기** → **어디 아래로**에 참고자료 → **옮기기** → 트리에서 10월 회의가 참고자료 밑으로 옮겨져 있다
- [ ] 3.6 자기 밑으로는 못 옮김 — 참고자료의 **옮기기**를 열면 **어디 아래로** 목록에 참고자료 자신과 그 밑(10월 회의)이 없다
- [ ] 3.7 하위가 있는 페이지 삭제 막힘 — 참고자료의 **삭제** → **하위 페이지가 있는 페이지는 삭제할 수 없다…**가 뜬다
- [ ] 3.8 넓게 보기 — 보기 화면 도구 줄의 **넓게 보기**를 누르면 글 칸이 넓어지고, 한 번 더 누르면 돌아온다

## 4. 편집기

회의록 편집 화면에서 한다. 본문 칸 바로 위에 **서식 단추 줄**이 있다.

- [ ] ★ 4.1 단추 줄 — **문단 형식**(본문·제목 1~3), **굵게·기울임·밑줄·취소선·코드**, **글머리 목록·번호 목록**, **인용·코드 블록·구분선**, **링크**, **표 넣기**, **되돌리기·다시**가 있다. 마우스를 올리면 이름과 단축키가 보인다
- [ ] ★ 4.2 모양 내기 — 글을 골라 **굵게**를 누르면 굵어지고 단추가 파랗게 눌린다. 한 번 더 누르면 풀린다. 제목 1·글머리 목록·번호 목록·인용·코드 블록·구분선도 하나씩 넣어 본다
- [ ] 4.3 기호로 모양 내기 — 줄 맨 앞에 **#**과 빈칸을 치면 큰 제목, **-**와 빈칸은 글머리 목록, **1.**과 빈칸은 번호 목록, **>**와 빈칸은 인용이 된다
- [ ] 4.4 단축키 — Ctrl+B(굵게), Ctrl+I(기울임), Ctrl+U(밑줄)가 된다
- [ ] ★ 4.5 링크 — 글을 골라 **링크**(또는 Ctrl+K) → 주소 https://example.com 넣고 **링크 넣기** → 링크가 된다. 주소 칸에 www.example.com(https 없이)을 넣으면 **http(s)로 시작하는 주소…만 링크가 된다**가 뜨고 닫히지 않는다
- [ ] 4.6 링크 빼기 — 링크 글자 안에 커서를 두고 **링크** → **링크 빼기** → 글자는 남고 링크만 빠진다
- [ ] ★ 4.7 표 — **표 넣기** → 3줄×3칸 표가 들어간다. 표 안을 누르면 단추 줄 끝에 **위에 행 · 아래에 행 · 왼쪽에 열 · 오른쪽에 열 · 행 지우기 · 열 지우기 · 표 지우기**가 붙는다. 하나씩 눌러 본다. 표 안에서 Tab은 다음 칸으로 간다
- [ ] 4.8 되돌리기 — **되돌리기**(Ctrl+Z)로 방금 한 것이 되돌려지고 **다시**(Ctrl+Y)로 돌아온다
- [ ] 4.9 붙여 넣기 — 다른 문서(워드·웹 페이지)에서 글자 색이 있는 글을 복사해 붙이면 글과 굵게·목록·표는 남고 **글자 색·크기·가운데 정렬은 빠진다** (정상)
- [ ] 4.10 메일 주소 — 본문에 tester1@example.internal을 치면 링크가 되지 않고 글자로 남고, 저장도 된다

## 5. 저장과 같이 고치기

- [ ] ★ 5.1 자동 저장 — 편집 줄에 **쓰는 대로 자동으로 저장된다**가 보인다. 글을 치고 5초쯤 손을 멈춘 뒤 **← 보기로** → 보기 화면에 친 글이 있고 버전 번호가 올라가 있다

- [ ] 5.3 제목 바꾸기 — 편집 화면 제목 칸을 고치고 1초 뒤 보기로 가면 새 제목이다. 트리에도 새 제목이 보인다
- [ ] ★ 5.4 두 사람 동시 편집 — 일반 창에 root, InPrivate 창에 tester1로 같은 페이지(회의록)의 **편집**을 연다
  - [ ] 편집 줄에 **같이 보는 사람: 시험일**(root 창) / **같이 보는 사람: …root 이름**(tester1 창)이 보인다
  - [ ] 한쪽에서 친 글자가 다른 쪽에 **곧바로** 보인다
  - [ ] 상대의 커서가 **색 막대와 이름표**로 보인다
  - [ ] 두 사람이 같은 문단을 동시에 고쳐도 **둘 다 남는다**
  - [ ] 둘 다 보기로 나간 뒤 이력(6절)에 자동 저장된 버전이 있고 고친 사람 이름이 적혀 있다
- [ ] 5.5 되돌리기는 내 것만 — 같이 고치는 중에 한쪽이 Ctrl+Z를 누르면 **자기가 친 것만** 되돌려지고 상대의 글은 남는다
- [ ] 5.6 권한이 빠지면 끊김 — tester1이 편집 중일 때 root가 Crew에서 tester1을 빼면 **몇 분 안에(기본 5분)** tester1의 편집 연결이 끊긴다 (확인 뒤 다시 editor로 넣는다)

## 14. 사용자 관리 (root로)

- [ ] ★ 14.1 찾기·거르기 — **찾기**에 tester를 넣으면 잠시 뒤 두 사람만 남는다. **상태** 고르기(전체·승인 대기·활성·잠김·정지)로 걸러진다

- [ ] 14.3 자기 역할은 못 바꿈 — root 자기 줄의 역할을 바꾸려 하면 **자기 자신의 역할은 바꿀 수 없다**
- [ ] ★ 14.4 비밀번호 초기화 — tester2 줄의 **비밀번호 초기화** → **이 사용자의 비밀번호를 초기화할까요?** → **새로 만든다** → 화면 위에 **임시 비밀번호 · tester2**가 한 번 보인다 → tester2가 그 임시 비밀번호로 들어가면 곧바로 새 비밀번호를 정하는 화면이 나온다

- [ ] 14.8 자기는 정지 못 함 — root 자기 줄의 **정지**는 눌리지 않고 **자기 자신은 정지할 수 없다**가 적혀 있다
- [ ] 14.9 위임 맡기기 — tester1 줄의 **위임** 칸에서 **스페이스 관리 전체**를 켠다 → tester1이 새로 고치면 위 막대에 **관리**가 생기고 **스페이스 관리** 화면에서 모든 스페이스를 본다. 끄면(거두면) 다시 사라진다
- [ ] 14.10 위임 — 분류 관리 — tester1에게 **분류 관리**를 켜면 **스페이스 관리** 화면의 **분류** 구획만 보인다. 확인 뒤 끈다

- [ ] 15.1 모든 스페이스 — **관리 → 스페이스 관리** → **모든 스페이스** 표에 모든 사람의 개인 공간과 팀 공간이 있다. **찾기**(이름·키)와 **상태**로 걸러진다
- [ ] 15.2 관리자가 건 중지 — 표에서 시험팀 공간의 **중지** → **멈춘다** → 상태에 **관리자가 걸었다**
- [ ] 15.3 주인은 못 풂 — tester1을 시험팀 공간의 주인처럼 시험하려면 tester1이 **직접 만든 팀 공간**(예: **시험일의 팀**)을 하나 만들게 하고, root가 그 공간을 중지한다 → tester1의 그 공간 관리 칸에 **관리자가 중지한 스페이스다.**와 **주인도 다시 쓰기로 풀지 못한다…**가 보이고 **다시 쓰기**가 없다. Crew도 바꾸지 못하고 까닭이 보인다
- [ ] 15.4 권한 받은 주인은 풂 — root가 tester1에게 위임 **관리자가 건 중지 풀기**를 켠다 → tester1이 새로 고치면 그 공간의 **다시 쓰기**가 생겨 푼다. 확인 뒤 위임을 끈다
- [ ] 15.5 주인이 건 중지 — tester1이 자기 공간을 스스로 **중지**하면 관리 칸에 **주인이 중지한 스페이스다.**, tester1이 **다시 쓰기**로 푼다
- [ ] 15.6 스페이스 지우기·되살리기 — root가 중지된 공간의 **지우기** → **스페이스를 지울까요?** → **지운다** → **휴지통**의 **지운 스페이스**에 있다 → **되살리기** → 안의 페이지와 함께 돌아온다
- [ ] 15.7 분류 — **스페이스 관리**의 **분류** 구획에서 새 분류 만들기·이름 바꾸기·지우기. 지우면 **…쓰던 공간 N개는 분류 없음이 됐다.**가 뜨고, 그 분류를 쓰던 공간은 분류 없음이 된다
- [ ] 15.8 템플릿 만들기 — 표가 있는 페이지 보기 화면 맨 아래 **템플릿** 구획을 펼친다 → 이름 **시험 회의록 틀** → **템플릿으로 저장** → **"…" 템플릿을 만들었다.**
- [ ] 15.9 템플릿으로 새 페이지 — 새 페이지 구획에 **템플릿** 칸이 생겼다. 그 틀을 고르고 만들면 그 내용으로 시작한다
- [ ] 15.10 템플릿 지우기 — 템플릿 구획의 **지우기** → 지워도 그 틀로 만든 페이지는 그대로다

- [ ] 16.7 관리자(admin)는 단계를 못 바꿈 — tester1을 잠시 admin으로 바꿔 감사로그를 열면 끝이 **— 보기**이고 **단계는 시스템 관리자만 바꾼다.** 확인 뒤 member로 되돌린다

## 17. 운영 설정 (root로)

- [ ] 17.1 화면 — **관리 → 운영 설정**에 **세션·계정 · 업로드·첨부 · 보존 기간 · LLM 대화** 네 묶음이 한 줄에 하나씩 보인다
- [ ] 17.2 바로 먹음 — **비밀번호 최소 길이**를 10으로 바꾸고 **저장** → **저장했다. 다음 요청부터 바로 먹는다…** → 가입 요청 화면의 비밀번호 안내가 10자로 바뀐다. 확인 뒤 8로 되돌린다
- [ ] 17.3 범위 밖은 저장 안 됨 — 비밀번호 최소 길이를 7로 넣고 **저장**하면 저장되지 않고 폼 위에 허용 범위를 알리는 말이 뜬다 (8자 아래로는 내리지 못한다)
- [ ] 17.4 첨부 크기 — **업로드 최대 크기 (uploadMaxMb)**를 1로 낮추면 1MB보다 큰 파일이 올라가지 않는다. 확인 뒤 되돌린다

## 18. LLM 질문 (선택)

체험판에는 사내 LLM 서버가 없다. **외부 AI 서비스(인터넷의 LLM)를 등록하지 않는다** — 질문과 붙인 문서가 그 회사로 나간다. 화면만 확인한다.

- [ ] 18.1 메뉴 — 위 막대 **LLM 질문**이 열리고, 왼쪽 칸에 **새 대화 · 내 지시문**이 있다
- [ ] 18.2 내 지시문 — **내 지시문**에서 지시문을 하나 저장하고 지운다
- [ ] 18.3 LLM 연결 화면 — root로 **관리 → LLM 연결**이 열린다 (등록하지 않고 화면만 본다)
- [ ] 18.4 위임 — root가 admin(잠시 admin으로 바꾼 tester1)에게 위임 **LLM 연결 관리**를 켜면 그 사람에게 **LLM 연결** 메뉴가 생기고, 끄면 사라진다. 확인 뒤 member로 되돌린다

## 19. 끄기·다시 띄우기

- [ ] ★ 19.1 끄기 — 까만 창을 누르고 **Ctrl+C** → 창이 멈춘다 (창을 그냥 닫았으면 **멈추기.cmd**를 누른다)
- [ ] ★ 19.2 다시 띄우기 — **시작.cmd**를 다시 누른다 → 이번에는 빨리 뜨고, 바꾼 root 비밀번호로 로그인된다. 만든 스페이스·페이지·첨부가 그대로 있다
- [ ] 19.3 떠 있을 때 다시 누르기 — 떠 있는 채로 **시작.cmd**를 또 누르면 **이미 떠 있다**를 말하고 브라우저만 연다
- [ ] 19.4 처음부터 다시 — 멈춘 뒤 푼 폴더의 **data** 폴더를 지우고 **시작.cmd** → 새로 시작된다 (root 첫 비밀번호가 다시 창에 보인다)
- [ ] 19.5 다 지우기 — 멈춘 뒤 푼 폴더를 통째로 지운다. PC의 다른 곳에는 아무것도 깔리지 않았다
