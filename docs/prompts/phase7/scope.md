# Phase 7 요청 원문

`CLAUDE.md` 11절. **사용자의 말을 그대로 둔다.** 요약하면 의도가 사라진다.

## 2026-09-23 · 무엇을 할지

앞선 대화에서 Claude가 "Phase 6은 끝났고 남은 것은 ① 돌리지 못한 검토 셋 ② 보류 20
③ 이미지 예산 여유 0"이라고 보고하고, 검토를 먼저 돌릴지 보류 20부터 잡을지 물었다.
그에 대한 답이다.

> 모두 다 진행하고 최종 결과만 보고해. 문제가 생기는 시점에서는 언제든 보고해도 돼.

### 이 말에서 읽은 것

- **"모두 다"** — 셋 다 한다. 순서는 Claude가 정한다. 그래서 검토를 먼저 돌리고, 거기서
  나온 지적을 보류 20과 함께 한 Phase에 담았다.
- **"최종 결과만 보고"** — 중간 진행 상황을 일일이 묻지 않는다. 다만
- **"문제가 생기는 시점에서는 언제든"** — 막히거나 판단이 필요한 것이 나오면 그때는 말한다.

### 이어지는 상시 지시 (앞선 세션에서 받은 것, 그대로 유효)

> 이 서버는 다른 프로젝트와 공유하는 인스턴스다. 아래는 절대 하지 마라.
> - docker system prune, docker volume prune, docker rmi 로 이름 확인 없이 지우는 것
> - 이름이 workfluence 로 시작하지 않는 컨테이너·이미지·볼륨을 멈추거나 지우는 것
> - 재부팅, 서비스 재시작, 다른 사용자 홈의 파일 편집
> - 공간이 부족하면 docker builder prune 과 docker image prune 까지만 하고, 그래도 부족하면 멈추고 남은 용량을 보고해라
