## 2026-09-30 — 착수 쟁점의 답 (Claude가 물은 것에 고른 안)

> 1가 2가 3가 4가 추천대로 진행해줘. 그리고 /clear 하고 진행하는게 더 좋으면, 어떻게 진행하면 될지 가이드해줘.

- 1번: 본인 email로 재설정을 누구까지 허용하나 — 고른 안 "**(가) member·admin만, root는 제외** (추천) — root의 메일함 하나가 뚫리면 시스템 전체가 넘어간다. root는 지금처럼 다른 root나 서버 담당자가 푼다(장애대응 7.29절)"
- 2번: "이메일이 기억이 안나시나요?"를 누르면 무엇을 적게 하나 — 고른 안 "**(가) 아이디 + 표시 이름** (추천) — 둘 다 맞는 활성 계정일 때만 시스템 관리자(root)의 알림에 간다. 응답은 늘 같다. 읽지 않은 같은 요청은 또 만들지 않는다"
- 3번: 댓글 칸에도 서식 단추 줄을 두나 — 고른 안 "**(가) 페이지 편집기는 전체 줄, 댓글 칸은 짧은 줄(굵게·기울임·목록·링크·코드)** (추천)"
- 4번: 서식 단추의 범위 — 고른 안 "**(가) 편집기가 이미 받는 것 전부** (추천) — 백로그의 것 + 밑줄·취소선·인라인 코드·인용·코드 블록·구분선. 표는 넣기(3×3, 머리 줄)와 표 안에서 행·열 더하기/지우기·표 지우기. 칸 합치기·나누기는 넣지 않는다"

함께 보인 것(따로 묻지 않고 그렇게 하겠다고 한 것 — 사용자가 다르다고 하지 않았다): 두 요청을 Phase 19 하나로, P1 FR-209a(로그인 전 자가 재설정을 두지 않는다)를 바꾼다,
두 길 모두 표시 이름 + 처음에 넣은 email, 메일에는 링크(30분·한 번), 맞든 틀리든 같은 응답·메일은 응답과 따로, 한 계정 5분에 한 통, 사내 계정·승인 대기·정지는 보내지 않는다,
재설정 뒤 세션·편집 연결을 끊고 잠금을 풀고 남은 관리자 초기화 요청 알림을 읽음으로, 메일이 꺼졌거나 `WF_PUBLIC_URL`이 비면 단추를 보이지 않고 관리 → 정책에서도 끈다(기본 켬).
