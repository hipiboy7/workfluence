### 설계 판단

- **복사 실패 대비를 넣은 이유**: 클립보드 API는 보안 컨텍스트(HTTPS 또는 localhost)에서만 동작한다. 운영은 nginx TLS 종단이라 정상이지만, 평문 HTTP로 접근하는 경로가 생기면 조용히 실패한다. 실패를 감추지 않고 값을 선택해 주고 안내한다.
- **아이콘은 인라인 SVG**: 외부 자원 0 규칙 (`CLAUDE.md` 7절).

## 3. 함께 고친 것 — 시드 계정에 의존하던 E2E

`승인 대기 계정은 로그인할 수 없다` 테스트가 시드 계정 `pending1`을 썼는데, 2026-09-15 사용자가 화면에서 그 계정을 승인해 상태가 `활성`으로 바뀌면서 테스트가 깨졌다(앱 결함 아님).

테스트가 **자기 계정을 직접 가입시켜** 확인하도록 고쳤다(`signup()` 헬퍼). 교훈: **사람이 만질 수 있는 시드 데이터에 테스트의 전제를 두지 않는다.**
